开始使用

一个二进制，
启动整个工作台。

从源码构建后，Vue 前端会嵌入 Rust 可执行文件。正式运行不再需要 Node.js，也不需要额外启动前端服务。

Node.js 18+Rust 1.75+Obsidian 推荐
安装 ObsidianBrain
git clone https://github.com/TiercelChow/ObsidianBrain.git
cd ObsidianBrain
make build
make install
$obsidian-brain versionobsidian-brain 0.1.0
1

构建与安装

运行 make build 构建前后端，再运行 make install 安装到系统路径。

2

启动服务

执行 obsidian-brain start，然后访问 http://localhost:9876。

3

连接 Obsidian

安装 Obsidian Local REST API 插件，在控制面板填写 Vault 路径、服务地址和 API Key。

4

配置 LLM

选择 OpenAI 兼容服务或 Ollama，填写模型、API Key 与 Base URL，并执行连接验证。

02

开始阅读

进入阅境轩，添加一个文件夹或 PDF 到书架。

  1. 选择“添加书籍”并填写本地路径。
  2. 补充书名、描述与自由类别。
  3. 点击封面开始阅读，系统自动记录位置。
  4. 长表格、代码和图表可在内容区内独立浏览。
03

留下小记

进入时光机，快速记录还不需要整理的内容。

  1. 创建小记，支持 Markdown 与图片。
  2. 使用标签标记主题或上下文。
  3. 通过关键词和日期返回历史记录。
  4. 在桌面端滚动内容区，手机端自然整页浏览。
04

管理任务

根据工作尺度选择短期待办或长期任务。

  1. 短期待办只需标题、描述、日期和重要程度。
  2. 长期任务可以添加任意层级子任务。
  3. 在根任务或子任务上追加进展和百分比。
  4. 通过日历查看开始、结束和跨日安排。
05

编译 Wiki

把多份原始资料整理为可以继续维护的知识条目。

  1. 选择主题和来源资料。
  2. 由 LLM 编译新页面或合并已有页面。
  3. 基于已编译 Wiki 进行带来源问答。
  4. 检查孤岛页、枢纽和缺失知识。
06

接入 AI 工具

让兼容 Tool API 或 MCP 的对话前端调用本地能力。

  1. 启动 ObsidianBrain 本地服务。
  2. 通过工具发现接口获取可用工具。
  3. 让 LLM 搜索笔记、添加记忆或推进任务。
  4. 执行结果和错误以标准化结构返回。

前往 Issues
这个 GitHub Pages 页面可以直接使用 ObsidianBrain 吗？

不可以。这里是完全静态的产品介绍和使用指南，不会连接你的本地数据。实际应用需要在自己的电脑上启动 `obsidian-brain` 后访问本地地址。

必须安装 Obsidian 才能使用吗？

阅境轩可以直接阅读本地文件夹和 PDF；但笔记搜索、Wiki、时光机与 Vault 集成能力建议配合 Obsidian Local REST API 使用。

任务数据保存在哪里？

当前任务中枢以本地 SQLite 为唯一权威存储；阅读书架、配置和部分运行状态也保存在本机数据目录。Markdown 笔记与附件仍在你的 Vault 中。

如何进行局域网访问？

默认服务可绑定 `0.0.0.0:9876`，同一局域网设备访问 `http://你的IP:9876`。若只希望本机使用，可将 `server.host` 设置为 `127.0.0.1`。

支持哪些 LLM？

支持 OpenAI 兼容接口与 Ollama。可以填写自定义 Base URL，因此也能连接实现兼容协议的第三方或本地服务。

正式运行还需要 Node.js 吗？

不需要。Node.js 只在构建前端时使用；最终前端资源通过 `rust-embed` 嵌入 Rust 二进制，运行时只需要一个可执行文件。
