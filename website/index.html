功能一览

你可以用它做什么？

阅读、记录和任务可以独立使用。想让 AI 帮你理解书籍，再开启书籍 Wiki。

读文档

阅境轩

把本地 Markdown 文件夹或 PDF 放进书架，打开就读；下次回来继续上次阅读。

  • 搜索目录中的文件、按标题跳转
  • 阅读表格、代码、LaTeX 公式和 Mermaid 图
  • PDF 缩放、页码定位和进度恢复
添加第一本书
记想法与照片

时光机

用一条小记保存文字、截图或照片；通过日期、关键词和标签找回，随时编辑和删除。

  • Markdown 正文，一条最多 9 张图片
  • 原图查看、缩放与切换
  • 图片保存在本机，缓存有大小上限
写第一条小记
安排与推进工作

任务中枢

短期待办记录一件事；长期目标拆成多级子任务，每一步都能记录进展，并在日历中查看日期安排。

  • 标题、描述、起止日期与重要程度
  • 子任务详情、进展与关闭说明
  • 任务 / 日历视图，归档后历史保留
创建并拆解任务
让 AI 理解一本书

书籍知识库

每本书一个独立知识库。智能编译跨章节归并概念、解释和关系，经人工审核后保存为可浏览、可引用的知识。

  • 书籍知识库只处理 Markdown 文件夹
  • Wiki 工作台查看正文、引用和历史版本
  • 原书只读，生成知识保存在本地 SQLite

前往 Issues
这个 GitHub Pages 页面可以直接使用 ObsidianBrain 吗？

不可以。这里是完全静态的产品介绍和使用指南，不会连接你的本地数据。实际应用需要在自己的电脑上启动 obsidian-brain 后访问本地地址。

必须安装 Obsidian 才能使用吗？

不需要。阅境轩读取本地文件，小记、个人任务和 Wiki 使用本地 SQLite，时光机原图保存在应用数据目录。旧小记图片可安全复制迁入，不会修改旧库文件。

任务数据保存在哪里？

任务中枢以本地 SQLite 为唯一权威存储；书架、小记和配置也保存在本机数据库中。时光机原图保存在数据库同级 timeline/images/，不再与外部笔记库双写。

书籍知识库保存在哪里？

实体、来源片段、配置文档、研究报告、Skill 和 Agent 审计保存在 ~/.obsidian-brain/brain.db；PPTX 等二进制成果保存在同一应用数据目录的受管附件区。Book Wiki 只读取 Markdown 文集且不会改写原文，阅境轩中的 PDF 阅读数据保持独立。

研究任务会访问哪些网站？

默认一个也不会。只有你在创建专题研究时主动开启外部研究、填写允许域名和最多请求次数，Harness 才能读取这些域名的 HTTPS 文本；系统拒绝重定向、IP 直连、内网地址和超额访问，并记录每次读取。

如何进行局域网访问？

将 server.host 设为 0.0.0.0 后，同一受信任局域网设备可访问 http://你的IP:9876。若只希望本机使用，设为 127.0.0.1；不要将端口暴露到公网。

必须使用 DeepSeek 模型吗？

不必。DeepSeek Harness 是执行器，可以接入其他兼容供应商；API Key 可在页面填写并保存到系统凭据库，也可使用环境变量。具体协议、模型和连接验证见模型配置。

正式运行还需要 Node.js 吗？

阅境轩、时光机和任务中枢不需要。若使用默认的 DeepSeek Harness 启动命令，则需要系统中存在 npm / npx；前端仍已通过 rust-embed 嵌入 Rust 二进制。
