前往 Issues
这个 GitHub Pages 页面可以直接使用 ObsidianBrain 吗？

不可以。这里是完全静态的产品介绍和使用指南，不会连接你的本地数据。实际应用需要在自己的电脑上启动 `obsidian-brain` 后访问本地地址。

必须安装 Obsidian 才能使用吗？

阅境轩、书籍知识库和任务中枢可以直接使用本地文件与 SQLite；时光机及 Vault 集成功能建议配合 Obsidian Local REST API 使用。

任务数据保存在哪里？

当前任务中枢以本地 SQLite 为唯一权威存储；阅读书架、配置和部分运行状态也保存在本机数据目录。Markdown 笔记与附件仍在你的 Vault 中。

书籍知识库保存在哪里？

实体、来源片段、配置文档、研究报告和 Agent 审计均保存在 ~/.obsidian-brain/brain.db。原始 Markdown 与 PDF 不会被改写。

如何进行局域网访问？

默认服务可绑定 `0.0.0.0:9876`，同一局域网设备访问 `http://你的IP:9876`。若只希望本机使用，可将 `server.host` 设置为 `127.0.0.1`。

支持哪些 LLM？

通用 LLM 功能支持 OpenAI 兼容接口与 Ollama；书籍问答和研究任务当前通过 DeepSeek Harness 的 ACP 适配器执行，Runtime 边界允许后续替换。

正式运行还需要 Node.js 吗？

阅境轩、时光机和任务中枢不需要。若使用默认的 DeepSeek Harness 启动命令，则需要系统中存在 npm / npx；前端仍已通过 rust-embed 嵌入 Rust 二进制。
