1. 什么是 ObsidianBrain

ObsidianBrain 是一个运行在你电脑上的知识助手。它连接你的 Obsidian 笔记本，帮你管理知识的完整生命周期：

📥
获取
从外部源抓取
或手动录入资料
→
🧠
整理
AI 自动摘要
提取概念和实体
→
🔗
连接
交叉引用
构建知识图谱
→
💡
洞察
发现缺口
生成新问题

2. 时光机 — 记录碎片想法

类似微信朋友圈，随时记录碎片化的想法。

✏️

写小记

点击「写小记」→ 输入内容（支持 Markdown）→ 可选添加标签 → 发布

🔍

搜索筛选

关键词搜索 + 时间快捷筛选（今天/7天/30天）+ 标签点击搜索

🖼️

图片

最多 9 张图片，自动压缩缩略图，点击查看大图左右切换

🔄

同步

在 Obsidian 中改了小记？点「同步」按钮更新系统数据

💡 小记保存在 Obsidian 的 Timeline/ 文件夹，你可以在 Obsidian 中直接查看和编辑。

3. Wiki 看板 — 知识库仪表盘

Wiki 看板是你的知识库「仪表盘」，一眼掌握全局。

📄 10

👤 4

💡 5

📚 1

🔗 0

🏥 知识健康度
🔴 孤岛页 2
🔵 缺失页面 1
🕸️ 枢纽 3
指标含义建议
🔴 孤岛页没有其他页面引用的页面补充交叉引用
🔵 缺失页面被提及但无独立页面创建存根页面
🕸️ 知识枢纽被引用最多的核心页面保持更新
💡 建议AI 生成的改进方向参考探索
⚡ 健康度分析较慢（约 10 秒），只在点击「刷新」时执行，不会每次进入页面都等待。

4. Wiki 工作台 — 操作知识库

四个功能页签，是你操作知识库的控制中心。

📥

Ingest 摄入

① 输入资料路径 ↓ ② AI 读取全文 ↓ ③ 生成摘要 ↓ ④ 提取实体概念 ↓ ⑤ 创建/更新页面
💬

Query 查询

① 输入问题 ↓ ② AI 读索引找相关页 ↓ ③ 综合回答+引用 ↓ ④ 可归档为论述
🔍

Lint 检查

① 扫描所有页面 ↓ ② 构建引用图谱 ↓ ③ 发现问题 ↓ ④ 可自动修复
⚙️

Schema 规则

编辑 AI 维护 Wiki 的规则手册：命名规范、摄入流程、查询流程

快速上手

下面覆盖最常用的配置与操作。更细的接口和开发设计保留在仓库的 README 与 docs 中。

01

首次配置

先让系统知道知识在哪里，以及需要使用哪个模型。

Obsidian Vault
Vault 路径 /Users/you/Documents/MyVault
REST API https://127.0.0.1:27124
API Key ••••••••••••••••
LLM 配置
提供商 OpenAI 兼容
模型 gpt-4o-mini
Base URL 使用官方默认

API Key 会保存到本地数据目录，不会由产品官网或 GitHub Pages 接收。

02

开始阅读

进入阅境轩，添加一个文件夹或 PDF 到书架。

  1. 选择“添加书籍”并填写本地路径。
  2. 补充书名、描述与自由类别。
  3. 点击封面开始阅读，系统自动记录位置。
  4. 长表格、代码和图表可在内容区内独立浏览。
03

留下小记

进入时光机，快速记录还不需要整理的内容。

  1. 创建小记，支持 Markdown 与图片。
  2. 使用标签标记主题或上下文。
  3. 通过关键词和日期返回历史记录。
  4. 在桌面端滚动内容区，手机端自然整页浏览。
04

管理任务

根据工作尺度选择短期待办或长期任务。

  1. 短期待办只需标题、描述、日期和重要程度。
  2. 长期任务可以添加任意层级子任务。
  3. 在根任务或子任务上追加进展和百分比。
  4. 通过日历查看开始、结束和跨日安排。
05

编译 Wiki

把多份原始资料整理为可以继续维护的知识条目。

  1. 选择主题和来源资料。
  2. 由 LLM 编译新页面或合并已有页面。
  3. 基于已编译 Wiki 进行带来源问答。
  4. 检查孤岛页、枢纽和缺失知识。
06

接入 AI 工具

让兼容 Tool API 或 MCP 的对话前端调用本地能力。

  1. 启动 ObsidianBrain 本地服务。
  2. 通过工具发现接口获取可用工具。
  3. 让 LLM 搜索笔记、添加记忆或推进任务。
  4. 执行结果和错误以标准化结构返回。
