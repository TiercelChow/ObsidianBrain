# 缓存结构与空间

北辰 Cache 将重复计算的键值块保存以减少计算。缓存命中能够避免重算，但需要读取和管理开销；未命中、容量不足及复用距离过长时收益降低。

示例张量缓存同时保存 K、V 两类值，理想载荷字节数为：

$$B = 2 L H D T b$$

L 为层数，H 为头数，D 为头维度，T 为缓存长度，b 为每个标量的字节数。这是载荷估计，不包含分配器、索引和对齐开销，不能直接等同于进程内存。

示例配置 L=8、H=4、D=128、T=1024、b=2，载荷为 16,777,216 字节，即 16 MiB。若只把 T 增为 2048，载荷变为 32 MiB，其他条件不变。

容量和生命周期是不同问题。CLOCK/LRU 控制空间使用，TTL 控制缓存项是否仍符合读取时效约束。
