# 手机任务中枢：轻卡片与上下文操作

## 范围

仅调整 ≤768px 的任务中枢。保留桌面双栏、共享双 Dock 动效、任务接口、文档版本校验与本地存储。手机二级 Dock 为四个图标：切换视图、搜索、筛选、新建。切换按钮显示目标视图图标，名称明确为“切换到日历/任务视图”；日历中新建默认选中日期。

## 实施顺序

1. 先写回归：直属子项稳定排序、活动流分类不丢记录、手机 Dock 单切换与唯一新增入口、移动表单日期范围和单抽屉。
2. 独立手机轻卡片列表：紧迫程度分组，独立圆角卡片内放标题及精简元信息，长期完成度放在次要信息行并按需显示细进度条；普通优先级/默认状态不重复展示，关闭状态仍有明确语义。保留加载、空结果、重试和筛选入口。
3. 手机详情：返回、唯一编辑；底部“子任务 / 进展 / +”上下文栏；直属子任务逐级查看，进展优先、状态操作记录可展开。子任务详情与编辑/新增/进展在同一抽屉内切换，取消返回原节点。
4. 手机表单：可选描述，日期复用系统滚轮；初版合并范围入口，后续按时光机改为开始/结束两格（见文末）。日历减少多余容器留白。桌面表单维持原布局。
5. 验证：单元测试、类型检查与生产构建；隔离内存数据的浏览器体验，覆盖 320/390px、桌面、深浅/护眼、长标题、多级节点、关闭任务和表单返回。不访问或写入用户任务。

## 验收边界

- 不静默完成任务；完成/取消仍提供关闭说明，级联仍由用户明确选择。
- 根任务进展包含子任务归因，子任务仅显示自身进展；操作记录不丢失。
- 正在保存时不允许重复提交或关闭编辑器；失败原位保留输入和可见错误。
- 图标操作有可访问名称，触摸目标至少 44px；不引入滚动时的大面积模糊动画。
- 不重复实现弹簧或改动共享 Dock 几何；减少动态效果模式不播放位移。
