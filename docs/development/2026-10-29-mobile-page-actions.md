# 手机页面悬浮主操作

## 范围与方案

- 首页现有入口是外观主题切换，不是 LLM 模型选择。本次只迁移该入口，浅色、深色、护眼循环不变；手机移除刷新按钮，自动刷新及失败重试保留。
- 阅境轩添加书籍、时光机写小记共用同一悬浮组件；电脑端布局、原表单、路径校验和持久化流程不变。
- 先以回归测试固定入口位置与显示条件，再实现共用材料和几何，最后用隔离页面验证视口、主题、开关面板及末尾内容。

## 实现边界

`MobilePageAction.vue` 只注册页面主操作（图标、可访问名称与原点击逻辑）；`App.vue` 提供按路由和所有者隔离的注册槽，`MobileDock.vue` 持有实际玻璃表面。圆形状态为 56px、图标 25px，保留按下压缩与平滑释放；复用 `data-glass="floating"` 与 CSS 光学层，不为小按钮增加 SVG 或独立观察器。

按钮右距为 `max(16px, safe-right)`；底距为导航预留高度、底部安全区与 12px 间隔之和，不依赖某个手机的固定屏幕高度。页面末尾保留按钮高度加间隔，滚动后末条内容可到达按钮上方。书架直接使用外壳内容高度，移除重复计算视口高度导致的底部覆盖。

首页顶部操作只保留桌面版本。书架手机搜索行只保留搜索，空态不另设加号；阅读模式不挂载悬浮添加。时光机手机搜索行改为搜索与时间筛选两列。

软键盘弹起时共享外壳状态隐藏悬浮按钮。MotionModal/图片预览打开时只隐藏按钮，不能隐藏文档；按钮低于模态层，关闭后恢复。减少动态效果时关闭缩放过渡，透明度/对比度设置沿用共享材料降级规则。

## 黑屏问题与回归

曾使用 `:global(html.motion-overlay-open) .mobile-page-action`：Vue scoped CSS 编译后丢失后半段，实际变成 `html.motion-overlay-open { visibility: hidden }`，从而隐藏整页和新增小记面板。

改为普通祖先选择器，Vue 只给目标按钮添加作用域标识。回归不仅匹配源代码，还实际调用 Vue `compileStyle`，断言最终选择器始终包含按钮，不能退化为对 html 的隐藏规则。隔离界面检查进一步断言新增面板、时间筛选和图片预览打开时，文档与对话框仍可见。

## 跨页圆形按钮 ↔ 子 Dock（2026-10-29）

- 圆形按钮与任务/Wiki 子 Dock 是同一个 `mobile-auxiliary-surface` 元素，不复制截图、不先淡出再挂载另一个表面。
- 切换到双层导航时，由右下角沿连续路径向左展开、由 56px 过渡到原子栏的 50px 高度；返回时按原路收回。表面圆角始终是自动钳制的胶囊轮廓，玻璃材料不交叉淡出；只有前景图标与导航内容交接。
- 位置、宽度、高度、两套前景透明度使用独立弹簧，response 0.34 / damping 1；每个时间步最多 1/120 秒。途中反向只改变目标，保留当前几何与速度；主形变约 0.2–0.5 秒达到 95%，后段轻柔归位。
- 导航文字和图标不做整体缩放，按最终内容宽度排布，通过表面裁切和透明度自然显露。退出页面的控件立即 inert，不能误触；前景淡出结束后清除缓存引用，不长期保留旧页面闭包。
- 已有双 Dock 滚动形变和底部预留不变。仅跨形态切页开启新弹簧；普通滚动直接跟随既有几何，避免叠加另一段延迟。页面注册有路由路径隔离，旧页面退出不能覆盖新操作，懒加载间隙保留表面但不允许旧操作响应。
- 首次进入直接显示正确形态。键盘、阅读/任务详情仍遵循原专注模式；减少动态效果时直接落位，运行中切换该偏好也立即停止形变。

验证脚本：启动隔离导航夹具后运行 `PLAYWRIGHT_MODULE=<模块路径> node scripts/verify-dock-route-morph.mjs`。覆盖 320/390/667px 的跨页双向形变、相同 DOM 身份与持续可见性、连续中间尺寸、快速反向、最终几何、无横向溢出和减少动态效果；额外打开小记面板复查黑屏回归。只操作合成数据，不写真实书架或小记。

验证结果：548 项前端测试与生产构建通过；隔离界面 12 组跨页形变、3 组途中反向，以及既有滚动收拢/展开、模拟键盘隐藏恢复、减少动态效果全部通过。三个入口在 6 组视口 × 3 种主题共 18 组界面验收中通过，桌面入口保持原样。键盘与手势使用浏览器模拟，不等同于 iOS/Android 真机验收。

- `npm run build`：类型检查与生产构建。
- 启动 `node tests/fixtures/mobileNavigation.mjs`，再运行 `PLAYWRIGHT_MODULE=<本机 Playwright 模块路径> node scripts/verify-mobile-page-actions.mjs`。
- 界面脚本仅接受版本 `preview`、存储路径 `/mock` 的隔离服务，阻止跨来源请求；不提交小记、书籍或配置，不接触真实数据库和模型。覆盖 320/390/667/768px 手机断点与 769/1440px 桌面、三种主题、滚动锚定、正文末尾、模态开关及阅读切换。
