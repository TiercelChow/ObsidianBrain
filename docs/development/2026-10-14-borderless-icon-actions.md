# 全系统纯图标按钮无边框化

## 范围

- 所有独立加号、关闭、编辑、删除、搜索、翻页、缩放、发送、更多等操作使用轻量无边框外观，不保留常驻填色或投影；带文字、进度百分比、日历日期的按钮不改变。
- UiAction 默认采用 quiet 外观；Vue 模板中的原生按钮、Element Plus 图标按钮、图标下载链接显式标注 data-icon-only，并由共享材质层统一绘制，避免页面专属规则覆盖。
- 状态勾选、开关、日期、任务卡片属于状态/内容控件，不将其误判成图标动作。折叠侧栏和按配置生成的图标子 Dock 另外覆盖。
- 保留按钮尺寸、位置、原有事件、语义颜色、加载/禁用、选中状态、键盘焦点和按压反馈。深色图片查看器保留高对比图标，危险操作保留危险色。
- Dock、阅读工具栏、弹窗及其光学材质不改动，只移除其内部按钮的重复玻璃外壳。

## 实施与验证

1. 阅读统一 UI 设计并使用 apple-design 的轻量控制、层级与反馈原则。工作流类 skills 不可用，执行等价的测试先行/验证/自审。
2. 通过 Vue 模板 AST 盘点全前端按钮，增加默认 quiet、原生图标标注和样式边界回归测试，先确认失败。
3. 修改共享组件与材质样式，按盘点结果补全明确标注；不使用 DOM MutationObserver 或运行时文本猜测，不给流式输出增加扫描成本。
4. 用隔离模拟数据核对桌面与手机的首页、阅境轩、时光机、任务、代码仓、Wiki，以及弹窗/图片查看器。无真实数据库写入或模型调用。
5. 运行全量前端测试、类型检查和构建，审查带文字按钮、容器和状态控件未被误改。

## 验证结果

- 模板盘点覆盖 19 个页面/组件的 95 处原生纯图标操作，全部显式标注；共享 UiAction 默认 quiet，Element Plus 弹窗/消息框关闭与日期/分页箭头统一覆盖。后续新增遗漏可被模板回归测试定位，不增加运行时扫描。
- 新增测试先失败再通过；全量 420 项前端测试、类型检查和生产构建通过（保留既有大资源包提示）。
- 隔离浏览器逐页检查阅境轩、时光机、任务、代码仓、知识库、工作台、问答、研究及配置：可见纯图标操作均为 0px 边框、透明底、无投影。
- 浅色/深色/护眼三主题核对时光机；危险色分别保留各主题色值。图片查看器的六个操作保持高对比浅色图标。
- 写小记弹窗：关闭按钮无边框；“图片”“取消”“发布小记”仍保留原有文字按钮外观。代码仓公共弹窗的关闭图标同样无边框。
- 390px 手机时光机无横向溢出，更多抽屉仍可开合；阅读栏四个按钮维持约 52px 点击宽度且无独立边框，外层阅读栏和 Dock 的玻璃边缘、光学层及布局仍保留。
- 自审核对事件、条件、尺寸及 DOM 内容未变；危险动作、禁用/加载、焦点、选中语义均保留。验证只访问隔离模拟服务，不触及真实书架、图片或数据库。未将浏览器尺寸验证当作真机性能测试。
