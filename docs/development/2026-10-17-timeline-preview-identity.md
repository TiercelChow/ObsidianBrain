# 时光机切图加载期间旧缩略图闪现

## 根因与范围

查看器的原图已按路径与重试次数设置 key，但当前及相邻的缩略图没有图片身份 key。切图后浏览器继续使用原来的 img 元素，新的 src 请求期间可以保留上一张已解码位图；因此页码已经变化，加载中的预览却会短暂显示旧图。

## 实施

1. 先补预览身份合同和隔离浏览器慢请求回归，确认旧实现的 img 节点被复用且仍持有旧图。
2. 仅让当前／相邻预览的元素身份跟随缩略图 URL。切图即卸载旧预览，请求未完成时使用现有加载指示；当前缩略图到达后仍可预览，再由原图渐入。
3. 保留原图 load/error 的当前元素检查、滑动弹簧、相邻缩略图数量、错误／重试及无障碍行为；不新增缓存、预加载原图或延迟定时器，不接触真实小记和照片。
4. 验证手机与桌面的慢缩略图、慢原图、连续切图、迟到响应、双向手势和失败恢复；运行前端全量测试及构建。

慢请求浏览器验收另复现：进入失败页后，上一轮程序切图留下的 `suppressClick` 会在画布捕获阶段吞掉重试按钮第一次点击。保持按钮不参与拖动，并在画布点击过滤中豁免真实按钮，不改变照片上的点击抑制逻辑；浏览器验证一次点击重试即可恢复。

使用 apple-design 的连续反馈与交互可中断原则；当前调试／计划／TDD／验证技能不可用，执行等价流程。不自动提交。

## 验证结果

- 先确认预览身份合同失败；隔离浏览器确认页码更新后仍复用旧 img 节点。重试按钮的单次点击恢复在修复前也复现失败。
- 修复后 `npm test` 464 项通过；`npm run build` 的类型检查、生产构建通过，保留既有大包提示。
- `scripts/verify-timeline-preview-identity.mjs` 使用内存小记与红／蓝／绿／黄 SVG、可阻塞原图／缩略图响应，在 390×844、320×568、1280×800 验收通过。
- 切图后 img 身份立即更新；若浏览器复用正确的已解码缩略图，像素必须对应当前图，否则保持空预览。逐帧采样当前及相邻预览，没有出现 src 与旧位图来源错配。
- 连续切图时释放旧请求不能把当前页标为原图就绪；当前请求释放后正常显示。反向拖动、原图失败后一次点击重试、关闭重开也通过。保留原图只加载当前页、三张缩略图和已有动画。
- 已目视核对原图等待阶段显示当前蓝色缩略图和加载指示；未读取实际小记、照片、缓存或数据库。隔离浏览器／服务已关闭，尺寸与鼠标 Pointer 模拟不等同于 iOS／Android 真机触摸验证。
