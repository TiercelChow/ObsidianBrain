# 全项目液态玻璃 UI 与交互统一

> 目标：完整审视应用及产品官网；桌面和手机分别组织内容与操作，统一材质、文字、布局和优雅动效。该目标不缩小为一次配色调整。

## 依据与当前证据

- 已阅读顶层设计、既有移动体验、材质、侧栏及双层 Dock 方案。已完成旧代码入口盘点及 19988 隔离实例桌面/390px 首页、手机知识库现场检查。
- 目前虽有集中材质入口，但几乎所有控件都采用同一灰白填色。内容、结构与浮动层辨识度弱；浅色辅助文字过淡，深色辅助文字也偏暗。
- App 仍有大量主题专属控件覆盖，页面留白/标题/表单尺寸存在局部规则；需按页面核对真实布局，不能用全局 overflow:hidden 掩盖内容缺失。
- 桌面展开状态切到手机时，导航会自动弹出。MotionModal/Drawer 接管回弹没有保留抓取位置，可能跳回从零开始的位移；取消手势也直接复位。
- 之前验收脚本引用的部分浏览器验证文件已不在仓库，不把历史文档的通过结论当作新版本证据。
- 使用 apple-design 的分层材质、即时反馈、空间一致性、可中断运动和无障碍原则。工作流技能不可用时执行等价 TDD/验证/自审，不委派未授权子任务。

## 设计语言

### 材质与色彩

1. 页面为无局部光斑、无粒子的稳定环境底色；不以发白背景模拟玻璃。
2. 导航/阅读栏/Dock/浮动操作为清透玻璃：较低体积填色、方向性薄亮边、深浅双边缘、受控接触阴影；不循环扫光，不做逐帧模糊。
3. 侧栏/内容导航为结构玻璃，颜色和厚度与浮动层区分；嵌套控件不再次取样滤镜。
4. 文档、对话、任务、记录是清晰内容平面，不将全文透在另一篇正文背后。卡片依靠边界/间距分组，不堆大阴影。
5. 模态面板更厚，只有一层聚焦遮罩；输入、按钮复用母层材质，输入轮廓贴圆角，键盘焦点仍清晰。
6. 保留浅色/深色/护眼及品牌强调色；主动作使用中性玻璃，不恢复实心蓝按钮。危险/成功/警告保留语义色。
7. 辅助文本需在稳定表面达到 4.5:1 目标；透明控件还要现场检查背景最不利处，不以 token 对比测试代替全部视觉验收。

### 排版与布局

- 统一正文、辅助、标签、标题四级字体、间距阶梯、控件/面板圆角和命中区域；路径/长标题自然换行或明确展开，图表/代码/表格局部横滑。
- 桌面：侧栏保持固定图标轨道，统一页面起点；列表-详情按业务分工，宽屏才并排，中间宽度自然降列；仅有操作意义的侧栏和底部区固定。
- 手机：单标题、主要内容全宽、搜索与创建同一轻控制行；根页双层 Dock，阅读/详情专用操作层。常用目标至少44px，键盘出现后提交入口仍可达。
- 标题不一味放大；通过字重/留白形成层级，避免首屏只剩控制区。配置高级内容分组，空态/加载/错误也用同一骨架。

### 运动

- 按下立即响应；只有可操作卡片产生按压反馈，静态统计/阅读内容不随点按缩放。
- 页面切换为克制短淡变/轻移；列表局部插入，非整页重播。工具型页面不复制重型渲染树。
- 手机面板从底部沿原路退出；抓取正在回弹的面板时保持当前位移，释放携带速度，取消后柔和归位。正文滚动/文本选择不抢为面板手势。
- 双层 Dock 保留现有连续收回/弧形下沉和弹簧，不改变已确认的导航方向与固定正文占位。
- 减少动态效果无位移/弹跳；减少透明度、高对比、强制色彩及滤镜不支持均有稳定不透明回退。

## 验证边界与数据安全

只使用隔离实例或无真实数据的UI夹具，不保存配置、不调用付费模型、不更改正式书架/任务/小记。保留用户CLAUDE.md改动。截图及桌面浏览器尺寸验证不能证明Safari/Android真机帧率；没有设备证据就明确列未验证，不宣称原生实时折射已实现。

本次代码范围已完成。验收证据与未验证的设备条件见 [验收记录](2026-10-03-unified-ui-acceptance.md)。真机性能、实际软键盘、OS无障碍偏好与字号放大仍需对应设备复测，不把浏览器尺寸模拟等同于真机验收。

参考：[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)。CSS backdrop-filter是背景图像滤镜，不等同原生光学引擎；这里采用轻量材质近似与可访问性回退。
