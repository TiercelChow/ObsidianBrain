# 移除灵感熔炉与智识雷达

## 范围与边界

- 删除两项功能的页面、路由、前端 API、专属样式、后端服务、模型、工具定义和注册、配置文件与专属设计文档。
- 代码仓保留原有功能和 `/code-repo` 地址，入口移至「日常」；删除「管理」导航分组。
- 桌面侧边栏与手机「全部功能」共用同一导航；手机 Dock 的四个快捷入口及动效不改。
- 未知/已移除地址统一回到首页，旧客户端调用下线工具返回工具不存在。
- 保留既有 SQLite 迁移编号/脚本、历史表和历史时间线事件解码。它们只用于升级兼容，不再有服务/API 写入或读取这些功能的记录。
- 不访问、清空或替换用户数据库、Obsidian 文件、书架；不改无关的 CLAUDE.md，不自动提交、安装或重启。

## 实施顺序

1. 阅读顶层、模块需求/开发设计，检查共享依赖和导航结构。
2. 先添加删除范围、导航归属和旧工具下线回归测试，验证失败。
3. 删除功能实现，清理启动与配置热更新中的专属依赖；保留通用 LLM/Wiki 能力。
4. 更新现行产品说明和工具文档；历史实施记录保持原样。
5. 验证前端测试、类型检查/构建，后端格式、Clippy、全部测试，以及隔离浏览器的桌面/手机导航。只使用临时测试数据。
6. 审查残留引用及 diff，确认历史数据兼容、其他模块不受影响。

项目要求的 writing-plans、test-driven-development、verification-before-completion、code-review、simplifying 技能不在当前可用目录中；以上执行等价流程。导航调整遵循 apple-design 的空间一致性原则，保持已有可打断 Dock 动画。
