# 液态玻璃一致性：第一版优化

## 目标与边界

依据 10 月 25 日只读排查与 apple-design 的材质分层原则，修复实际失效并让功能层清透、内容层安静。保留顶部开放式渐变、双 Dock 的几何与弹簧、照片手势、PDF/Mermaid 渲染和全部存储行为。不添加环境光斑，不逐帧修改滤镜，不为每个卡片注册光学观察器。

项目要求的 writing-plans / TDD / verification 等工作流 Skill 当前未提供，执行等价的先测后改、浏览器验证、自审流程。

## 实施顺序

1. 先写失败回归：独立图标外层承载材质、手机配置扁平容器、共享选择轨道、废弃变量、面板透明度与可访问性。
2. 统一材质角色：inset（嵌入式选择轨道）、group（小工具组）、flat（不着色的布局壳）。选中块消费公共光泽和边缘，不另加背景滤镜。独立小标签使用同一选择材质。
3. 时光机查看器/阅境轩全屏返回使用“玻璃外壳 + 无边框图标”，不改变点击、键盘、图片平移/翻页与位置所有权。
4. 手机 Wiki 配置外层明确 flat，分区为单层内容材质。清除图谱/结构切换/Skill 的不存在变量，不以补一套旧 token 掩盖问题。
5. 面板保留厚度但减轻中心遮盖和模糊，边缘反光与表单文字优先于整块亮框。官网演示来源弹层跟随系统面板。
6. 独立内存 API 夹具验证真实页面的 computed style、三主题、窄屏、选择状态、图片查看器、图谱和无障碍实底回退；运行前端/官网测试及构建。

## 验证边界

只使用只读检查或隔离内存数据，绝不修改正式书架、小记、任务或模型凭据，不运行付费模型。Chromium 尺寸/触摸模拟不等同 iOS/Android 真机验证；Safari 保留现有 CSS 光学回退。

## 第一版完成与验证

- 共享面板中央模糊由 16px 降为 12px，三主题填色适度减轻；面板和普通按钮改用更柔和的内反光，不改变 Dock 的材质参数与弹簧。辅助文字在面板内提升为 secondary；对黑/白极端背景经过现有遮罩与面板叠加后的主、次文字对比度进行回归检查，均不低于 4.5:1。
- 时光机预览采用独立关闭/翻页玻璃壳和底部工具胶囊；图标保持无边框，背景光学层不接收输入。只有底部胶囊新增一个有界自动透镜，圆形外壳为无观察器 CSS 模式；原图片身份、加载、平移、翻页和重试状态机未改。
- 新角色用于任务/阅读切换、任务快速筛选/类型/详情、研究结果、实体调整、日期范围、图谱/日历工具组；书架分类、时间筛选与 Wiki 导航共享选择材质。已有滑块独占位置/变换，未叠加第二个选中动画。
- 手机配置的 flat 壳在浏览器 computed style 中确认为透明、无阴影、无滤镜；每个分区只有一层内容材质。图谱节点和 Skill/实体调整的废弃变量已替换为当前语义 token。
- 前端 496 项测试、官网 60 项测试及两端生产构建通过。构建仍提示既有的大分块、Reader API 静态/动态导入及 VueUse 注解警告，无新增构建错误。
- 图片隔离验收：390×844、320×568、1280×800 下检查三主题的玻璃壳、无边框图标、包含关系和安全区；减少透明度、高对比、强制色彩模式保留正确实底。逐帧缩略图身份、过期请求、拖动翻页、重试及重新打开通过。
- 配置隔离验收覆盖 8 个尺寸（320px 到 1440px）、手机三主题、长知识库名、独立图标操作和完整 Skill 内容。日期滚轮 9 个尺寸/主题组合及桌面回退通过，嵌套弹窗、触摸与鼠标阻尼、取消/确认/清除语义保留。
- 对实际开发页面执行了只读首屏/弹层检查并观察截图；未保存配置、修改业务数据或触发模型。源码保持未提交，供用户先验收效果。

## 第二轮：补齐首页、搜索和全部选择框

用户指出第一版首页卡片、阅境轩/任务搜索和选择框仍缺少可感知的玻璃效果。原因是这些区域仍走 content/普通 field/嵌套降级规则，并非渲染缓存问题。

1. 先增加失败回归，分别约束首页三类卡片、三个阅读搜索入口和两个任务搜索入口。
2. 首页使用 dashboard 角色和纯 CSS 光学层：低遮盖填色、弧面亮边、背景柔化；不为每张卡片分配 SVG 贴图/观察器，不改变卡片布局、内容或跳转。
3. 搜索框使用 control 角色和同样的独立背景层，替代旧嵌套降级；正文输入和图标不使用前景滤镜，焦点反馈贴合圆角。
4. 所有 Element Plus Select（含多选、可搜索、禁用、弹窗内和开发样例）通过公共选择器适配：触发框与独立浮层使用 CSS 光学伪元素，不改组件注册、不增加全局 DOM 观察器，选项仍由原组件处理键盘/选择/滚动。
5. 独立浏览器夹具检查三主题、手机/桌面、选择与搜索、长选项和无障碍回退，核实 computed style 和实际截图；保留所有第一版未提交工作，不进行提交。

- 人工查看三主题手机与桌面截图，确认实际材质、菜单完整展开状态和文字清晰度。数据只来自内存夹具，不接触用户配置、业务数据或模型服务；仍未提交。

## 第三轮：以用户指定页面为参照完成全页面材质

第二轮单独增加的 dashboard/control 材质仍与现有页面不同，且主内容仍被旧的实底 content 适配器覆盖。本轮以「我的任务」整个列表卡片为卡片参照，以时光机/Wiki 工作台为搜索参照，用户的新要求优先于旧文档“正文容器不使用玻璃”的设计选择。

1. 新增先失败的页面覆盖契约，明确首页、阅读中栏、小记、任务详情、日历、代码仓、知识库/Wiki/问答/研究/配置的全部主容器。
2. card 与 structural 消费同一套填色、光泽、5px 背景柔化、薄边缘和内反光，不再维护 dashboard 特例，不为内容卡片创建 SVG、观察器或 JS 滚动处理。
3. 现有 glass-surface/knowledge-surface/glass-panel/repo-card/pane 同步接入，空态和懒加载也覆盖；浮动层、弹窗及 flat 壳保持各自权重。嵌套卡片只做有厚度的着色和边缘，不重复采样背景。
4. Reader/Task 删除第二轮特有的透镜，与 Timeline/Wiki 共用 search 角色、44px 高度、14px 圆角、字体、焦点与边缘。只统一样式，原有书架筛选、目录搜索、小记查询和实体查询保持独立。
5. 扩展隔离浏览器验收覆盖全页面真实内容、主题/手机/桌面及交互；重新执行全量测试、生产构建和人工截图检查。保持现有未提交修改、不更改任何业务数据。

## 方向按钮与图标居中（2026-10-26）

## 关闭与其他图标的统一排查

- 按 apple-design 的一致性原则，审查所有 Vue 模板的独立图标操作，而非只替换关闭图标。新增失败回归，排出 25 处字体字符绘制的关闭、清除、加号与缩放按钮，全部换用现有 Element Plus SVG；保留辅助名称、原事件和无边框样式，不新增图标依赖。
- 共享居中规则覆盖独立原生按钮、UiAction 及组件库弹窗/抽屉/确认框的关闭按钮：以真实 SVG 盒 flex 居中，移除字符基线与不对称 padding 的影响。保留阅境轩底栏大图标、图片工具和局部点击区域的既有尺寸；搜索清除按钮单独扩大点击区域。
- 修复原生 Element Plus 图标按钮加载时仍显示原插槽图标的问题，加载状态只呈现一个居中的旋转图标。禁用状态、展开旋转、减少动态效果和键盘行为不变。
- 研究阶段的展开提示、任务完成/取消标记和进入提示也改用 SVG；阅读器/书架/预览的警告、小记空态不再依赖系统 Emoji，避免不同平台的字形、颜色与基线差异。小记 Markdown 勾选标记改用 CSS 线条，不更改内容解析或存储。

## 多级子任务弹窗与状态标记

- 根因：二级及更深子任务的返回按钮原本是标题的同级 flex/grid 列，出现时会改变标题横向起点。返回按钮移到上级路径工具行，标题和属性独占后续行，手机和电脑统一正文左边距；弹窗内容服从模态框宽度，修复原先电脑内容 680px 超出 540px 模态框造成的偏心。
- 移除子任务弹窗底部两个操作。唯一编辑入口仍在顶部；添加子任务与记录进展均使用各栏目右侧的共享加号，空子任务列表仍可新增，已关闭任务保留原先禁止追加的限制。动作仍绑定当前 `drawerNode`，关闭表单后保持所在层级，不修改存储/API/版本校验。
- 新增轻量 `TaskStatusMark`，任务树与弹窗子项共用 22px SVG 状态标记：完成为实心圆勾，取消为横线，进行中为圆点；标记不处理事件，树的状态编辑按钮保留独立 44px 点击区域。子项操作名称包含状态，不能仅凭绿色识别完成态。
- 窄屏日期范围与截止提醒允许按整项换行，不再把日期或“截止”两字挤断。保留现有玻璃材质、返回/关闭路径、内容切换和减少动态效果策略。
- 先失败回归后实现；前端 518 项测试、类型检查、生产构建及 `git diff --check` 通过。扩展原方向控件隔离验收，在 320/390/900/1440px × 三主题共 12 组中验证三级下钻/返回标题偏移不超过 0.75px、长标题/空子项、两个加号的正确目标、表单取消后层级保留和关闭任务入口限制。390px 深色额外启用正常动效，其余覆盖减少动态效果；人工查看手机长标题及电脑状态标记截图。全部数据来自内存夹具，未写正式任务，代码未提交。

## 全部下拉菜单的完整圆角

- 根因是 `motion.css` 的旧贴边菜单几何：向下展开时上两角被设为 0，向上展开时下两角被设为 0，与现有独立玻璃光学层不一致。先用失败的源码回归和真实 Element Plus 菜单复现，浏览器读到上角为 `0px`、下角为 `14px`。
