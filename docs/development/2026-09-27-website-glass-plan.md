# 官网液态玻璃材质对齐

## 范围与方案

应用端 Token 筛选高度修复及此前材质／侧栏修改先提交，再调整官网首页、使用手册、LLM Wiki 架构页。保留内容、锚点、导航、逐步入场动效和 GitHub Pages 静态发布方式；不调用本地业务 API，也不操作实际书架和数据库。

使用 apple-design 的功能层材质、固定边缘高光与可读性原则。官网静态 CSS 复用应用 `materials.css`，共享三主题填色、光学参数、圆角亮边和不透明回退，不引入 Vue 或后端依赖。官网的适配层只映射已有页面元素：

- 页头、功能分段导航、手机章节导航：通透浮动层及边缘高光。
- 手机展开菜单：较厚的菜单层，保证文字可读。
- 手册和架构目录、产品预览侧栏：结构层；预览内部不再叠加滤镜。
- 功能说明、图表、正文、示意卡片：清晰内容层，无逐卡片模糊。
- 主按钮、主题／菜单／GitHub 按钮和选中分段：中性玻璃动作，保留主题强调色用于图标与语义状态；代码区域及书籍插画保留自身颜色。
- 删除背景光斑和功能卡片局部径向高光；反光限制在边缘，不把正文洗白。

## 执行与验证

1. 先添加失败契约测试及生产站点浏览器验收脚本。
2. 接入共享材料并改造旧局部 blur 配方，区分大表面／内部控件，保留现有布局和可打断交互。
3. 检查三主题 × 桌面宽／窄窗、手机竖／横屏：无重叠、导航可展开、正文及架构图可局部滚动；亮边不阻挡点击。
4. 检查减少透明度、高对比、强制色彩、减少动态效果、无脚本阅读、可重复滚动入场。
5. 官网测试、生产构建、现有架构图验收、隔离浏览器与截图人工检查，自审后交付。CSS 是原生 Liquid Glass 的轻量近似，不宣称实时折射或真机帧率达标。

项目指定的流程技能不在当前可用目录，沿用先失败测试、实现、验证、自审流程；只使用临时本地静态预览，不发布、不推送。
