# 手机知识问答跟随 Dock 回收空间

## 根因与范围

问答是固定视口内的消息滚动面板，但页面和外壳底部始终扣除双层导航 120px。Dock 收为一层 62px 后，剩余 58px 没有交还给对话。

依据顶层设计、REQ-08、Wiki 手机布局、双层 Dock 与全局 UI 方案，使用 apple-design 的连续布局与可中断运动原则。只改变手机问答的可用高度；普通列表仍使用稳定的双层预留，不改桌面、会话、检索、存储或已有 Dock 动画。工作流计划/TDD/调试/验证技能不可用，执行下述等价流程。

## 实施

1. 先补失败回归：问答布局共享 Dock 的显示进度；外壳与对话扣减同一实际占位；键盘隐藏导航时归零；布局引起的滚动不得反向驱动导航。
2. App 仅给手机问答发布 Dock 的 sink/travelY 与可见性。问答占位按子栏顶边计算：`主高 + 子高 + 间隔 + (主高 - 子高) / 2 × sink - (主高 + 子高 + 2 × 间隔) / 2 × travelY`，不小于主栏高度。CSS 使用既有高度 token，不另开动画时钟。已有空隙覆盖轻微视觉回弹。
3. 问答外层禁用页面纵向滚动，并同步修改底部内边距和内部视口高度。消息区域独立滚动，关闭浏览器隐式滚动锚定。底部阅读时通过 ResizeObserver 跟随末尾；翻看历史时不强制跳底。
4. Dock 识别滚动时扣除视口变化造成的自动夹取/底部定位，仍保留同一帧真实反向拖动的增量，避免收放反馈环。
5. 全量前端测试、构建、自审；隔离长会话验证展开/收起、反向、在底部/翻历史、短屏/窄屏与桌面。验证不能访问真实数据库或调用模型，不自动提交。

## 验证记录

- 新的布局与滚动回归先失败；修复后全量 444 项测试及前端类型检查、生产构建通过（仅既有大分包提示）。
- 隔离夹具通过可见的验收按钮重放 wheel 意图与滚动，驱动真实 Dock 监听器；全部 API 使用合成长会话，未访问真实数据、供应商或模型。该控件仅由测试服务器注入，不包含在正式应用。
- 390×844：Dock 展开时消息区高 572px、输入框底部 695px；收起时消息区高 630px、输入框底部 753px，增加 58px。子栏顶边相应由 716px 下移到 774px，两端静止时输入框留有 21px 距离，预留间距亦能覆盖运动中的轻微回弹。外层滚动范围为 0，没有遗留空白可滑入。
- 历史位置在单次 160px 手势后只前移 160px，没有自动跳底；反向手势恢复原位置。末尾状态点击圆球展开后仍保持末尾（亚像素误差 <1px），没有导航反馈振荡。
- 320×640 窄屏和 667×375 横屏同样保留 21px 间距，无横向溢出，外层滚动范围为 0。横屏会隐藏既有的知识库选择行，保留输入框操作。真机触摸/软键盘仍需设备复测。
- 恢复 1280px 桌面后，手机联动变量移除，Dock 不渲染，外壳保留既有 32px 底部内边距。
