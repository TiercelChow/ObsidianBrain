# Wiki 工作台独立滚动与问答入口修复

## 范围与原因

- 桌面工作台的 MotionSwap 新增了两层容器，但原先的剩余高度只约束了内层网格；实体列表因此撑开页面。补齐容器高度传递，不使用新的固定像素高度。
- 左侧列表和右侧正文分别滚动，边界不向外层页面传递；列表标题保持固定。
- 不改变 1100px 以下的单栏导航、手机整页滚动、详情返回后的列表位置恢复。
- 问答历史的新对话入口保留加号图标，采用共享 UiAction 的 quiet 外观。移动端放在历史抽屉标题旁，保留无知识库/生成期间的禁用规则。
- 根据后续反馈，回答下方的运行检查、保存候选、深入研究（含异常时补存入口）同样使用 quiet 外观：无常驻边框和投影，悬停/按压时才显示圆形柔和底色；保留 44px 点击区域、20px 图标、键盘焦点、加载与禁用反馈。共享组件的默认玻璃外观不变。
- 回答底部统一一行：参考来源及数量靠左，操作靠右；来源默认收起，每条回答独立展开，来源列表在该行下方自然展开。无来源时只显示右侧操作，无运行记录的旧检索回答仍可展开来源。只在本轮输出结束后显示。保留来源预览、键盘操作、展开状态和减少动态效果支持。

## 实施与验证

1. 添加回归测试并先确认失败：动画容器高度链、桌面滚动边界、移动端约束隔离、两端共享按钮及禁用状态。
2. 修改工作台布局和问答按钮；不改全局动画组件或后端接口。
3. 运行前端测试和类型检查/构建。
4. 使用独立只读模拟 API 验证长列表、长正文、暂停提示、矮屏，以及手机详情返回、新对话入口。不访问实际数据库、不触发模型调用。
5. 自审修改范围与样式冗余。项目指定的工作流类 skills 当前未提供，按对应的测试先行、验证、自审流程执行；界面设计遵循 apple-design。

## 验证结果

- 新增的 3 项回归测试先失败、修改后通过；前端全量 407 项测试通过，类型检查及生产构建通过（仍有既有的大体积资源提示）。
- 隔离预览提供 70 个实体、60 段正文、30 条历史会话；所有未声明操作被拒绝，不连接实际后端。
- 1440×900：外层滚动高度等于视口 900px；列表滚动 1800px 时，正文和页面仍为 0。列表到底后继续滚动，页面仍为 0；正文亦可独立滚动。继续加载能从 60 条增加至 70 条。
- 1440×600：正文、列表自动随剩余空间缩小，暂停提示出现后仍不撑开页面。
- 390px 手机端：动画容器不启用高度约束，整页滑动和实体详情返回正常，无横向溢出。320px 历史抽屉边界位于视口内。
- 首轮验证两端新建按钮的点击、键盘 Enter、手机关闭抽屉与无知识库时禁用行为。后续按反馈恢复加号并统一轻量按钮样式，再进行验证。
- 自审：不修改存储、问答调用和全局切换动画逻辑；共享按钮增加显式可选外观，默认玻璃外观不变。删除覆盖共享按钮的旧局部样式。
- 后续视觉修正验证：全量 410 项测试及构建通过。浏览器实测加号和三项回答操作为透明底、0px 边框、无投影、44×44px 点击区域；手机端无横向溢出，历史抽屉加号点击后正常新建并关闭抽屉。键盘导航有可见焦点；默认玻璃外观、两种外观下的禁用/加载行为均有回归测试。
- 回答页脚验证：新增 3 项回归测试先失败后通过，全量 413 项测试及构建通过。桌面和 320px 手机端来源入口与三项操作位于同一行、操作靠右，手机展开后来源卡片为单列，无横向溢出。验证了默认收起、键盘展开/收起、收起区 inert、多条回答独立展开、无来源时操作右对齐、旧检索回答展开来源，以及卡片仍通过弹窗读取历史证据快照。未修改或读取真实用户数据。
