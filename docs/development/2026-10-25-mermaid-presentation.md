# 阅境轩 Mermaid 排版与阅读体验

## 范围与技术选择

保留 unified Markdown → 可视区增强 → 官方 Mermaid SVG 的现有路径，不改书架、阅读进度或原始文件。沿用 Mermaid 11.16.0，接入与其兼容的官方 `@mermaid-js/layout-elk@0.1.9`，避免 Mermaid 12 的 Safari 17.4+/ES2024 兼容门槛。0.1.9 的布局入口分块加载，不把第二套渲染引擎带入阅读首屏。

流程图默认 ELK，其他图种保留各自原生渲染/布局；文档 frontmatter 指定的布局、节点样式继续由官方解析器处理。公式保持原始 `$$...$$`，保证范围仍为官方支持的流程图和时序图，不声明所有图种支持公式。

沿用官方 Mermaid 字符串转义规则：流程图 HTML 标签的矩阵换行需要四个反斜杠，经 Mermaid 还原后成为 TeX 的两个反斜杠；样例与浏览器测试检查矩阵实际有两行，不只检查存在 KaTeX 标签。不会全局增删用户源码里的反斜杠来猜测其意图。

## 实施计划与职责

1. 先写系统配色、布局选择和查看器几何测试。
2. `mermaidTheme.ts` 将系统的背景、正文、次级文字、强调色和字体 token 转为 Mermaid 的具体色值，不维护第二套浅色/深色/护眼色板。
3. `mermaidRuntime.ts` 共享配置/渲染串行队列，等待系统与 KaTeX 字体，隔离测量 DOM，拒绝过期任务。原文仅经过官方解析器，安全模式保持 strict。
4. `useMarkdownRender.ts` 继续按视口提前增强；主题切换只调度可见/即将可见图，失败不丢弃旧图。首次失败保留可展开源码和重试入口。
5. 独立样式防止正文 CSS 影响 HTML 标签排版。正文完整适宽显示图表，按 viewBox 等比缩小，不横向裁切；小图不强制放大。全屏查看时恢复自然尺寸以供阅读与缩放。
6. 查看器复用系统玻璃工具栏、无边框图标按钮和弹窗焦点/滚动锁；新增可读尺寸/完整查看，支持鼠标、单指平移和双指缩放。缩放图复制时重写 SVG ID、样式和 marker 引用。
7. 开发环境 `/dev/mermaid` 提供真实阅读管线、原版和 beautiful-mermaid 的对比。后者仅为开发依赖，不替换正式引擎，不进入生产构建。固定样例不读写真实数据。

## 具体兼容修复

Mermaid 11 类图 `.edgeTerminals foreignObject` 含固定 CSS `width:9px;height:12px`，会覆盖官方已测量写入的 SVG width/height 属性。仅移除这一位置的冲突尺寸，使用已测量的属性；不在布局后替换公式或猜测文字尺寸。

独立测量容器使用真实字体、有效宽度和 `visibility:hidden`，不使用 `display:none`。每次渲染后 finally 释放容器；所有查看器 PanZoom/ResizeObserver/动画帧和模态锁在关闭时释放。没有新增无界 SVG 缓存。

真实 Reader 还会将正文公式的 inline-block、vertical-align 和局部滚动规则应用到图表内部 KaTeX，造成测量容器与最终页面的公式高度不同。图表自身的 scoped themeCSS 同时用于测量与显示，隔离这些正文规则；不靠扩大节点猜测修复。

矩阵还会触发 Size3/Size4 字体，若仅预热普通/Size1/Size2 字体，会在首次显示后发生括号宽度变化。渲染前预热这些字体；特殊字母表或字体粗细首次使用产生新字体请求时，等待字体就绪并最多重新测量一次，避免发布回退字体的尺寸。

## 验证

- 单元测试：系统 token 派生、护眼主题、图种布局、手机可读比例、适配/居中、边界约束。
- `frontend/scripts/verify-mermaid-presentation.mjs`：隔离 Vite 服务，不配置真实 API 代理；20 组源码覆盖中文长标签、混排、多行/Markdown 标签、嵌套子图、复杂连线、公式/矩阵、时序图、状态/类/ER/甘特/饼/思维导图/时间线、作者样式与布局、错误源码。
- 真实浏览器检查 foreignObject 文字尺寸与容器尺寸、有效 viewBox、页面不横向溢出、三主题、图表独立 ID、移动端平移/双指缩放、320px 窄屏与横屏、关闭后的资源清理。
- 前端全量测试与生产构建；确认生产构建没有 MermaidLab / beautiful-mermaid 入口。

浏览器自动化为 Chromium。真实 iOS Safari、macOS/Windows 内置 WebView 的触摸与字体仍需实机验收，不能将 Chromium 模拟触摸等同于真机验证。

## 第二轮体验调整

- 默认连线由 basis 曲线改为 linear，并将 ELK 节点摆放策略设置为 NETWORK_SIMPLEX，减少分支的短阶梯：保留布局引擎避让节点的路径，不再将折点插值为波浪或 S 形；描边采用圆角连接。作者显式指定的线形与布局仍由官方渲染器处理。示例“下一步 → 研究报告”额外检查出节点后的路径保持同一高度。
- 正文与预览的 SVG 保留原始 viewBox/宽高属性，但展示使用 max-width:100% 和 height:auto；宽图等比完整适配文档内容宽度，查看器不受此缩放限制。
- 全屏画布 absolute inset:0，占据完整视口。移除可见标题栏和底部提示文字，保留对话框的无障碍名称与操作说明。
- 关闭按钮与底部控件浮在画布上，复用 data-glass=floating 与系统 CSS 光学层；工具栏外部区域不截获拖动，安全区与窄屏样式仍生效。
- 新增回归检查：整图无横滚/变形、默认路径不包含样条控制点、画布占满视口、两处控件使用系统玻璃、横竖屏后控件不溢出。
