# 手机双层 Dock 与滚动形变

## 交互约定

- 主导航保留阅境轩、时光机、任务中枢、全部四项。桌面侧栏不变。
- 有子栏目时，上方浮起更窄、至少 44px 点击高度的子 Dock。Wiki 五页、任务/日历、灵感三种模式共用同一组件；筛选器不当成导航。
- 手指上滑（scrollTop 增加）展示双层；手指下滑（scrollTop 减少）主导航逐步收为右侧圆球，子 Dock 同步下沉到圆球左侧。无子栏时只收起主导航。
- 点击圆球展开；切换页面重新展开。可在形变途中反向滑动，不等待前一次动画结束。
- 内容预留最大双层高度，形变不改变正文高度，避免页面跳动与滚动反馈环。
- 阅读/任务详情保留原有专用操作栏；弹窗内滚动、程序滚动、问答自动跟随不驱动 Dock。键盘弹起隐藏 Dock。
- 减少动态效果时直接切换两种状态；减少透明效果时使用实色。缩起的导航不能获得焦点，展开入口可键盘操作。

## 实施顺序

1. 为滚动进度、方向抖动、释放目标、边界过滤编写纯函数测试（先红后绿）。
2. 添加作用域内子导航注册，页面状态仍由原页面管理，不复制业务状态或发请求。
3. 共用 Dock 组件与滚动控制器，复用现有弹簧物理，监听用户手势及实际滚动。
4. 移动端移除重复的顶部子导航，统一底部预留空间；桌面保持原布局。
5. 单元测试、类型检查、生产构建、隔离浏览器测试。验证 320/390px、小横屏与桌面，包含动画中断、嵌套滚动、路由切换、无障碍和模态场景。

## 验证边界

浏览器验证只用本地 Mock 服务，禁止操作真实书架、数据库、供应商或 LLM。保留不相关的工作区修改，不自动提交或推送。

## 已实施

- `MobileDock.vue` 统一主导航与子导航材料、几何形变、可访问性；收起时主导航不可聚焦，圆球展开后恢复键盘焦点。
- `useMobileSubnav` 采用作用域注册与所有权清理，离开的旧页面不能清除新页面导航；原页面继续负责路由与业务状态。
- `useMobileDockMotion` 捕获实际触摸/滚轮滚动，复用 `stepSpring`，区分内部滚动、自动滚动、回弹、输入编辑、弹窗和键盘；不会改正文布局。
- Wiki 顶部五栏目、任务视图切换和灵感模式在手机端迁到底部。Wiki 配置内部的分区选择器保留，避免第三层 Dock。

## 验证入口

- `npm test`：229 项通过，包含 8 项新增 Dock 逻辑与组件契约测试。
- `npm run build`：类型检查与生产构建通过（现有打包体积及第三方注释告警保留）。
- `WIKI_MOBILE_LAYOUT_ONLY=1 node scripts/verify-wiki-reliability.mjs`：320×568、390×844、667×375、1440×1000；五页、配置分区、正文高度、弹窗与横向溢出检查。
- `MOBILE_DOCK_ONLY=1 node scripts/verify-wiki-reliability.mjs`：真实 CDP 触摸移动、途中反向、圆球与子栏位置、44px 点击区域、稳定正文预留、自动跟随、内部滚动、单层导航、路由清理、键盘展开和减少动态效果。
- 默认浏览器回归：桌面与手机的供应商配置、问答恢复、来源快照、编译报告、研究阶段与运行检查器全部通过。

Playwright 可通过 `PLAYWRIGHT_MODULE` 指定已有安装路径。键盘高度通过独立 visualViewport 模拟，仍建议在 iOS/Android 真机体验；测试不会访问生产 API。
