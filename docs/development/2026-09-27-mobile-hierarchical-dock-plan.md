# 手机双层 Dock 与滚动形变

## 交互约定

- 主导航按「首页 → 阅境轩 → 时光机 → 任务中枢 → Wiki」排列五项（2026-10-04 更新）。移除「全部」及其模块菜单。首页作为总览与外观切换入口，日常三项相邻，Wiki 进入 `/knowledge`，知识模块各页均选中 Wiki。桌面侧栏不变。
- 代码仓仅在桌面展示；手机没有入口和首页统计，也不请求仓库统计。手机书签访问 `/code-repo` 或从该页缩到手机断点时返回首页，不删除仓库数据或桌面功能。
- 有子栏目时，上方浮起更窄、至少 44px 点击高度的子 Dock。Wiki 五页、任务/日历共用同一组件；筛选器不当成导航。
- 手指上滑（scrollTop 增加）主导航收为右侧圆球，子 Dock 沿圆球上方的弧线滑到左侧，同时收窄、增高；手指下滑（scrollTop 减少）沿原路恢复双层。无子栏时只收起主导航。
- 变换后子 Dock 高度与圆球直径均为原主 Dock 的 62px；两个部分及间隔合起来维持原主 Dock 的完整宽度。上方子 Dock 仍保持较小的 50px。
- 点击圆球展开；切换页面重新展开。可在形变途中反向滑动，不等待前一次动画结束。
- 收起和展开落位时有克制的弹簧回弹：两层轻轻抬起再归位，主栏/圆球有轻微横向拉伸与纵向压缩；子栏不缩放，避免文字变形和点击区域变小。静止尺寸仍为原主 Dock 的 62px。
- 内容预留最大双层高度，形变不改变正文高度，避免页面跳动与滚动反馈环。
- 阅读/任务详情保留原有专用操作栏；弹窗内滚动、程序滚动、问答自动跟随不驱动 Dock。键盘弹起隐藏 Dock。
- 减少动态效果时直接切换两种状态；减少透明效果时使用实色。缩起的导航不能获得焦点，展开入口可键盘操作。

## 实施顺序

1. 为滚动进度、方向抖动、释放目标、边界过滤编写纯函数测试（先红后绿）。
2. 添加作用域内子导航注册，页面状态仍由原页面管理，不复制业务状态或发请求。
3. 共用 Dock 组件与滚动控制器，复用现有弹簧物理，监听用户手势及实际滚动。
4. 移动端移除重复的顶部子导航，统一底部预留空间；桌面保持原布局。
5. 单元测试、类型检查、生产构建、隔离浏览器测试。验证 320/390px、小横屏与桌面，包含动画中断、嵌套滚动、路由切换、无障碍和模态场景。

## 验证边界

浏览器验证只用本地 Mock 服务，禁止操作真实书架、数据库、供应商或 LLM。保留不相关的工作区修改，不自动提交或推送。

## 已实施

- `MobileDock.vue` 统一主导航与子导航材料、几何形变、可访问性；收起时主导航不可聚焦，圆球展开后恢复键盘焦点。
- `useMobileSubnav` 采用作用域注册与所有权清理，离开的旧页面不能清除新页面导航；原页面继续负责路由与业务状态。
- `useMobileDockMotion` 捕获实际触摸/滚轮滚动，通过 `stepDockSpring` 复用 `stepSpring`，区分内部滚动、自动滚动、回弹、输入编辑、弹窗和键盘；不会改正文布局。
- 手势只更新目标，显示进度由同一个持续运行的弹簧跟随（response 0.44，速度上限 300 进度单位/秒）。跟随中间位置时采用临界阻尼；两端落位使用 0.76 阻尼，并通过至多 1/120 秒的积分步长保持不同刷新率下弹性一致。相比前一版，主体变换加快约三成，隔离触摸验证的 5%→95% 变换约 350ms。松手后继续沿当前显示速度归位；反向只改目标、不重启时钟、不跳到旧目标。
- 物理进度允许轻微越过端点，`dockGeometry` 单独约束布局范围，`dockRebound` 软限制视觉反馈：抬升小于 4px，主栏横向拉伸小于 1.2%、纵向压缩小于 6%。不会越界增大正文预留，也不会缩放子栏的 44px 点击区域；减少动态效果时直接切换并关闭弹性变形。
- 取消先横向收拢、再纵向下沉的分段运动。主栏宽度、子栏高度与圆角共用同一个弹簧进度；主栏以 `1-(1-t)^4` 向右收拢，子栏沿连续曲线绕过收拢中的胶囊（横向 `t(2-t)`、纵向 `t^4`），横向收窄、纵向增高和曲线位移从开始到结束同步变化，中途没有保持不动的阶段。
- 删除条形材质与独立圆球材质的早期交叉淡入淡出，以及装饰表面和重复的控件容器。主栏始终是同一块不淡出的玻璃表面，从完整条形、短胶囊连续收回到右侧圆球；文字和图标在收拢中逐步隐去，圆球入口接替。子栏轨迹为整个移动中的胶囊预留空间，不通过提前隐藏主栏规避相交。圆角外接矩形可以在空角相交，但实际玻璃表面保持间隙。
- Wiki 顶部五栏目与任务视图切换在手机端迁到底部。Wiki 配置内部的分区选择器保留，避免第三层 Dock。
- 五项导航只增加列数，不改变主栏 62px 高度、玻璃材质、圆球收拢轨迹、双层预留和回弹参数。320px 视口仍保证每项至少 44px 触控范围；圆球按当前首页/阅读/记录/任务/Wiki 显示对应图标。
