# 全页面操作减噪与可感知交互

上一轮的创建按钮及底层弹窗修复不代表全页面完成。本轮按操作类型和真实路径验收，不按用户举例的数量收尾。

## 操作规则

- 编辑、删除入口、刷新/同步、查看、下载、返回、关闭采用统一图标动作，保留可访问名称、桌面提示、44px 命中范围及忙碌状态。删除确认、保存/取消、启动付费运行、审核应用等有后果或语义不明确的动作保留简洁文字。
- 底部操作菜单保留行名称，不能把菜单也变成无法理解的图标墙。
- 去除没有摘要/描述/说明等占位废话、重复实现说明。用户正文、来源边界、状态、错误、费用及数据删除说明不裁剪。

## 实施边界

保留已确认的双 Dock 物理曲线、真实业务接口与已有未提交修改。不碰实际数据库、图片、书籍、凭据；只在隔离夹具验证。使用 apple-design 的按下反馈、空间连续性及减少动态效果规则。新增共享图标动作与内容切换组件，先补回归，再逐页接入，最后全量构建和浏览器核验。

## 落地与验收

- `UiAction` 统一编辑、删除入口、查看、刷新等常用图标操作。保留可访问名称、提示、禁用、危险色与加载状态，手机命中范围为 44×44px；底部菜单仍保留易理解的行名称。
- `MotionSwap` 接入任务列表/详情、逐层子任务、Wiki 实体、配置分区/文档/Skill 文件、研究阶段/报告/检查器。入场与离场同时进行，退出内容保留且不可交互；不使用先消失再出现的 `out-in`。
- 书架、任务树、小记、代码仓与知识库列表接入位置重排。退出元素冻结尺寸和位置，不再占据正常布局；仅动画活动期间覆盖旧卡片定位/悬停样式，解决筛选结束才突然跳位的问题。
- 阅读器书架/正文使用持久挂载与独立内容层过渡，避免切换时重建 PDF。页面级转场仍只改变透明度，避免变换整个页面使手机固定 Dock 跟着移动。
- `MotionContent` 向嵌套内容开关传播退出生命周期，避免父页面清空选中项后，弹窗内容提前消失。增加嵌套回归，先复现失败再修复。
- 修复任务树折叠后，隐藏子孙节点被兜底逻辑当作孤立节点重新加入的问题。切换拆解/进展时保留折叠状态。
- 一般加载状态（原图、PDF、目录、预览、实体检索）采用有可访问名称的转圈；删除/恢复警告、来源可信边界、费用与运行失败说明仍保留。

### 实际界面核验

隔离预览仅使用合成书籍、任务、供应商和会话，所有 API 都被本地夹具接管，不连接真实数据库或发起模型调用。

- 手机 390×844：任务列表/详情与子任务、拆解/进展切换、Wiki 列表/正文返回、问答结果操作与末尾来源、研究面板切换、供应商编辑弹窗/取消、配置文档切换、书架筛选与阅读返回。
- 浏览器计算样式确认书架退出元素绝对定位，剩余卡片执行 380ms 的位置重排；内容切换具有实际位移与透明度过渡。
- 手机供应商编辑/删除按钮均为 44×44px、同一行；新增与标题同一行；核验页面没有横向溢出。
- 桌面 1440×1000：任务列表展开宽度 350px，选中后收为 68px；详情扩展且列底对齐，原双 Dock 动画不变。
- 支持 `prefers-reduced-motion`；本轮没有声称真实手机帧率或 GPU 性能已验证。

### 自动验证

前端全量测试 404 项通过，类型检查与生产构建通过，`git diff --check` 通过。构建仍有原有的较大分包等提示；本轮不涉及 Rust、真实数据迁移或提交代码。
