# 2026-10-07 界面密度与连续交互优化

## 范围与边界

- 单层手机 Dock 始终展开；只有存在子 Dock 的页面参与原有滚动变形。
- 时光机桌面日期导航共用一条轴；手机时间筛选采用底部面板，不挤动小记。
- 图片预览分离图片、序号和操作区，保留原图缩放、拖动、切图与错误恢复。
- 任务子 Dock 加入搜索、筛选入口；复用原查询状态，在底部面板调整条件。
- 手机书架三列，封面按宽度调整高度，保留 44px 书籍操作目标。
- 精简重复的创建按钮文字、装饰性说明；字段、状态、错误与危险操作说明保留。
- 根据 apple-design 的空间连续性原则，公共弹窗/抽屉共用可反向、中断、承接速度的弹簧；保留焦点与滚动锁直到离场结束。常用图标与分段切换补齐按压及移动反馈。

## 实施与验证

1. 为单层 Dock、连续弹簧、时间轴、预览分区、子 Dock 操作和三列书架补回归测试，先验证失败。
2. 修复公共交互与三个业务页面，保持桌面布局和业务 API 不变。
3. 全量前端测试、类型检查与生产构建；审查监听器、帧任务、焦点及减少动态效果。
4. 仅用隔离模拟服务器验收 320/390/430px 手机及桌面；不得访问或修改用户数据库、图片、书籍、凭据，亦不重启用户服务。

## 验收要点

- 单 Dock 在向前、反向滚动后均保留五个导航，双 Dock 的原有曲线与方向不变。
- 面板关闭途中重开、拖动途中松开无跳变；面板离场完成前背景保持不可滚动。
- 竖图/横图/加载/失败时序号不与缩放控件重叠，安全区得到保留。
- 搜索、筛选可通过任务子 Dock 完成；按钮可访问名称与当前条件反馈完整。
- 三列封面不横向溢出，标题不被更多按钮挤成单字列。
- 不为静态内容增加无意义运动，不持续动画大面积模糊；减少动态效果模式取消空间运动。

## 验证记录（2026-10-08）

- 前端全量测试 391/391 通过；类型检查与生产构建通过。构建仍有原有的大包及混合动态导入提示，本次不扩大到打包拆分。
- 新增真实弹簧和 Vue 组件测试：目标反向时保留位置/速度，只保留一个帧任务，关闭途中重开、拖动交接、减少动态效果和卸载清理；父页面清空选中项后，离场内容不消失，重开恢复新内容。
- 隔离页面验证 320/390/430px 三列书架，无横向溢出、封面重叠；书籍操作目标为 44px。验证中修复纵横比被最小高度反向撑宽的问题。
- 320/390px 竖图的序号与控件间距为 12px；横图、加载和失败状态保留同一底部布局。
- 1440px 桌面时间导航圆点和竖线中心差为 0px。
- 手机任务搜索通过子 Dock 打开，输入条件后列表由 18 项变为 1 项；时间筛选不挤动正文，文件抽屉关闭后释放滚动锁。
- 面板切换时，较慢退出的旧面板不向背景触发按钮恢复焦点；焦点归还仅由当前最上层面板完成，且不打断新打开的面板。
- 单层 Dock 在隔离页面双向滚动后保持五项展开。双层 Dock 沿用原来的曲线与方向，几何/弹簧回归测试通过；本次浏览器的辅助滚动不等于真实手指输入，不据此声称真机手势帧率。
- 验收仅访问 5220 隔离模拟服务；未修改实际书籍、小记、图片、数据库、模型配置，未重启用户服务。
