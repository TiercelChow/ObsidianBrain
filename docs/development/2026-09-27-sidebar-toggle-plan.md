# 侧栏展开／收起定位修复

## 原因与边界

全局导航侧栏的宽度、padding、justify-content 和 v-show 离场同时变化。文字离场期间仍参与 flex 居中，随后 display:none 又触发一次布局；分组标题立即消失，按钮行高度也随状态变化，选中指示层在过渡开始时测量后会落后于实际位置。

本次不修改路由、业务数据、Dock 运动或玻璃材质，只修复全局导航侧栏及其手机「全部功能」面板。

## 实施与验证

1. 先增加失败契约与隔离浏览器逐帧采样，检查各图标、Logo、收起按钮的坐标及选中指示层。
2. 三处共享固定图标轨道；保持行高、分组占位及内边距，文字只改变透明度／可见性，不移除布局参与者。桌面导航行使用紧凑的 40px 高度，标准 768px 窗口可完整显示导航；手机仍保留 70px 触控卡片。点击按压的变换原点也锚定图标。
3. 文字隐藏不移除链接可访问名称；收起按钮暴露展开状态。手机标题、关闭按钮保持挂载，整块面板沿原路径退场，不在退场中改变内部布局。
4. 保留可反向切换的宽度过渡；减少动态效果时切换宽度为即时状态更新，保留轻淡变。指示层使用组件局部引用测量。
5. 使用 apple-design 的固定空间锚点、可打断运动与可访问性原则；项目命名的工作流技能不在可用目录，采用同等先失败测试、实现、验证、自审流程。
6. 检查三主题、桌面宽／窄窗、手机竖／横屏、连续开关、快速反转、键盘导航及减少动态效果。测试仅使用隔离 Vite Mock；不读取或修改用户数据库。

## 验证结果

- 新增 3 项侧栏契约测试：实现前失败，实现后通过；前端完整测试 260/260 通过，`vue-tsc -b` 通过。
- 隔离浏览器检查 1440×1000、1024×768、390×844、667×375，覆盖浅色、深色、护眼三主题。正常开关和 70/130ms 快速反向切换中，图标、Logo、底部开关与各自基准中心偏移均小于 1px，选中指示层与按钮行保持对齐。
- 手机关闭过程逐帧检查关闭按钮与导航项固定相对位置；模块点击后自动关闭仍有效。键盘展开／收起和减少动态效果通过。
- 原移动 Dock 回归检查通过（320/390/667/1440px），保持既有收回、弹性落点、可打断运动、输入键盘避让和嵌套滚动行为。
- 人工检查桌面展开／收起及手机面板截图；`git diff --check` 通过。截图和运行夹具位于临时目录，没有读取实际书架、运行 Harness 或操作数据库。
- `make build` 通过，最新前端已嵌入 release 程序。仅构建，没有安装、启动或替用户重启服务，也没有提交代码。
