# 阅境轩位置书签

## 需求与边界

书架中的每本书维护自己的书签，覆盖 Markdown 文集、文集中的 PDF 和独立 PDF。书签包含标题、Markdown 笔记、文件与定位信息；不写入原书。阅读工具栏提供书签入口，支持当前位置新增、浏览本书全部书签、查看/编辑/删除笔记、跨章节跳转。正文位置有可点击标记。手机复用底部弹层，桌面复用系统弹窗与玻璃材质，保持浅色/深色/护眼主题。

Markdown 保存块序号、块文本摘要、块内比例及文档滚动比例；优先匹配文本块，找不到时退回文档比例。PDF 保存页码、页内纵向比例和横向比例，缩放后以新页面尺寸恢复。原文改动无法保证语义位置永远不变；文件失效时保留笔记并显示错误，不删除数据。

## 存储与接口

- 新增 SQLite v60 `reader_bookmarks` 表，关联 reader_books；软删除书籍不自动抹除笔记。
- `list_reader_bookmarks`、`save_reader_bookmark`、`delete_reader_bookmark` 工具按书隔离。单书最多 1000 条，单笔记 128KiB，单书笔记总量 8MiB；超限拒绝写入，不截断。
- create 使用服务器 UUID；更新和删除要求 revision，事务校验书籍仍有效、文件归属、类型、位置、文本及容量。陈旧写入返回冲突，保留本地草稿。
- list 读取完整书签，客户端仅保留当前书；切书、迟到读取和未完成保存均绑定书籍 ID，不能污染其他书。
- 原文件仅由现有只读阅读工具加载。不存在的文件、PDF 页码超过新版本页数须明确提示。
- 独立只读离线快照暂不增加写入能力；正常在线阅境轩通过本地服务持久化。

## 实施计划与验收

1. 先补临时数据库 CRUD、隔离、校验和并发版本测试，以及定位纯函数测试。
2. 实现迁移、存储、Tool JSON Schema 与注册，更新工具文档。
3. 新增定位工具、书签状态与列表/编辑/预览组件；使用现有安全 Markdown 渲染服务，不引入另一套解析器。
4. 接入 Reader 和 PdfViewer，跳转覆盖原进度恢复并等待目标布局就绪；缩放、主题、窗口变化后更新标记。
5. 隔离模拟数据验证手机/桌面 MD 与 PDF 新建、查看、编辑、删除、刷新、跨文件跳转、三种主题、失败与快速切书；不操作用户数据库，不重启真实服务。
6. 前端全量测试/构建、Rust fmt/clippy/测试，审查新增 API 边界、错误反馈与资源释放。

## 实现与验证（2026-11-10）

- 电脑阅读工具栏和全屏浮层提供书签入口；手机点按底部文档名打开书签，不改变两侧四按钮。点按正文或选择文字后打开面板，用 + 建立该位置的书签。未指定位置时使用当前可见阅读位置。
- 选中文字仅用于定位，新建笔记始终留空，不自动把选中文本填入引用。已有笔记的查看、编辑和存储内容保持不变。
- 列表标题直接跳转；眼睛图标查看笔记。正文侧边标记直接查看对应笔记，同位置多条合并计数，可返回全书列表查看其他条目。
- 笔记复用安全 Markdown Worker 与按需高亮/图表管线；预览、编辑与删除在同一玻璃弹层内完成。未保存草稿关闭需确认，保存中不允许重复提交。失败保留草稿；文件缺失、PDF 损坏或页码越界不会删除笔记。
- 跳转先取消普通进度恢复；在 1.8 秒布局稳定窗口内重定位段落/PDF 页内点，抵消翻页退场、PDF 适宽及图片布局的迟到更新。真实触摸、鼠标点按、滚轮、键盘或目录跳转立即取消校正，不持续强制拉回。
- 可见标记按一次段落索引批量定位，不为每条书签反复扫描全文；不在滚动时重新解析笔记。切书、过期读取、快速切文档与卸载均清理监听器、观察器、Worker 和短期校正计时器。
- Rust：604 项通过、6 项既有忽略项；fmt、Clippy 零警告与后端构建通过。覆盖 CRUD 持久化、版本冲突、跨书隔离、路径/位置/类型边界、数量上限、软删除保护、迁移重放及 Tool Schema。
- 前端：555 项测试、类型检查和生产构建通过。隔离 Chromium 验证 390px 手机与 1440px 桌面、三种主题、MD/PDF 页内定位、跨章节、刷新、笔记渲染、编辑/删除、草稿冲突、来源缺失、损坏 PDF 及桌面全屏。另验证选中文字后新建笔记仍为空、选中段落定位有效、编辑标题不改已有笔记。无页面异常、无真实 API 请求。iOS 真机和其他浏览器未在本轮验证。
- 后端新二进制已编译，但未替换正在运行的服务；下次启动时按正常流程执行 v60 迁移。未操作用户数据库、原书或书架记录。代码高亮修复与书签功能按独立批次提交，便于回溯。
