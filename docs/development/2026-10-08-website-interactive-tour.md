# 官网专业文案与交互演示

## 目标与边界

首页使用明确、克制的产品语言，说明产品定位、能力和适用场景，移除聊天式表达。安装与具体操作保留在手册。仅修改 website，沿用三主题材质、公开静态站点与现有 Pages 路径；不访问业务 API、模型或用户数据库，不发布或提交代码，除非用户另行要求。

## 功能演示

将现有四个静态展示面板改为有状态的交互演示：

- 阅境轩：书架选择 → 文档阅读 → 章节定位 → 阅读位置恢复。
- 时光机：编辑内容 → 发布小记 → 标签筛选。
- 任务中枢：长期任务 → 子任务拆解 → 进展记录 → 日历日程。
- 书籍 Wiki：来源同步 → 主题编译 → 人工审核 → 引用问答 → 来源预览 → 报告与 PPTX 交付。

每个流程包含步骤导航、播放 / 暂停、上一项 / 下一项，画面内的按钮可直接进入对应步骤。使用固定示例数据，不伪造真实模型执行或下载链接；真实操作从手册进入。所有演示明确标识数据与成果为示例。

## 动效与可访问性

### 2026-10-09 连续轮播调整（当前合同）

播放器连续执行阅境轩 → 时光机 → 任务中枢 → Wiki 的全部 17 个步骤，然后循环回到阅境轩，不再在单个功能末尾停止。每步按内容停留 1.3–2.2 秒，一轮约半分钟；最后一步同样获得完整展示时间。选中页签、画面、步骤和说明由同一播放状态同步。

步骤切换采用约 240ms 的交叉淡入淡出，功能切换约 280ms；不等待出场完成才入场，不叠加旧的整面板 560ms 模糊动画。布局在当前宽度预先测量并保留所有步骤所需高度，手机步骤栏也保留统一高度，避免正文和后续页面上下跳动。转场副本不参与点击、焦点或辅助技术，及时回收，支持快速手动切换。

手动选择步骤或点击演示内容暂停自动播放，播放按钮从当前位置继续。上一项 / 下一项可跨功能。离屏、后台和手动暂停保留当前步骤的剩余时间，返回后不会重播整步。减少动态效果不自动开始，显式播放仍可用；所有计时器、观察器和转场在销毁时释放。

以下为 2026-10-08 的初版背景，单功能末尾停止的行为已由以上连续轮播替代。

遵循 apple-design：即时按压反馈、短距离内容过渡、连续且可打断的进度变化，不增加背景光斑或逐字闪烁。自动演示仅在画面进入可视区域时开始一次；离开视口、切换应用或页面隐藏时停止计时。手动切步骤停止自动播放，不抢焦点；流程末尾停止，支持重播。减少动态效果时不自动播放，仍可手动阅读全部步骤。

HTML 保留示例和文案作为无脚本内容；增强后控件才出现。支持键盘切换页签、清晰焦点、44px 触控区域。手机以画面优先排列，步骤可换行，内容不能横向溢出。

## 实施与验证

1. 为专业文案、步骤可用性与纯状态机先添加失败测试。
2. 重写首页和手册入口；实现演示模型、生命周期控制、HTML 画面与样式。
3. 官网测试和构建；浏览器检查三主题、桌面 / 390px / 320px，手动操作、播放暂停、来源关闭、后台 / 离屏暂停。
4. 自审计时清理、键盘操作、减少动态效果回退与真实功能边界。

项目指定的流程技能当前不可用，使用明确设计、测试先行、验证与自审的等价工作流。
