# 全项目 UI 统一验收记录

日期：2026-10-03。范围为应用10个路由（任务/日历两种状态）和官网首页、手册、Wiki架构页；没有修改业务数据或调用付费模型。

## 实现与自审

- `tokens.css`唯一维护浅色、深色、护眼的文字/尺寸/语义色，应用与官网直接共享。删除index内联控件样式和App三主题重复覆盖，避免懒加载页面改变其他模块弹窗。
- 材质分为稳定内容面、结构层、浮动层、模态层；清透中心、薄亮边与接触阴影承担层级，不加页面光斑、不逐帧动画模糊。嵌套字段不再次过滤背景。
- 控件状态共享圆角焦点、禁用、错误、语义颜色和触摸尺寸；深色主题今日数字、勾选与日期端点采用专用对比前景色。
- 面板重抓取保留当前呈现位置，反向拖动连续；取消后弹簧归位，非交互卡片不点按缩放。保留已确认的双层Dock运动路径。
- 手机书籍只显示一个明确的44px操作入口；任务子树隐藏容易误触的小状态按钮，详情编辑仍完整保留。子任务和其他页面自有面板继承父层最大高度，解决底部操作被截断。
- 修复320px任务日历负边距越界、横屏时光机日期筛选越界、Wiki Runtime开关被动作分组样式误选中的问题。
- Wiki单列进入正文从顶端开始；返回列表恢复点击位置并清除详情路由参数，不抢后台应用焦点。旧请求不能覆盖新选择；Markdown子树挂载后再进行图表等增强。
- 官网保留文案、安装/手册及Wiki架构；手机顶部按钮均可点击，品牌不被挤出，滚动呈现距离与模糊更克制。

## 验证边界

- 未运行iOS Safari/Android真机，未实测真实软键盘、设备旋转、系统放大字号及长时间帧率/电量。
- 减少动态、减少透明度、高对比和强制色彩已保留实现并通过源码契约回归，没有宣称本次逐一切换了所有操作系统偏好。
- CSS材质是轻量玻璃近似，不是macOS原生实时折射引擎。业务表单采用较厚表面保证可读性，正文不强行做成透明玻璃。
- 本轮UI验证不对智能编译、模型回答质量或PPT内容做新验收；使用已有隔离产物，不把UI检查等同于模型质量评估。
