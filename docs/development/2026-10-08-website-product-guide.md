# 官网功能说明与操作手册重整

## 目标

首次访问者不用先理解 Rust、ACP、Skill 或知识编译架构，就能回答「有哪些功能、能干什么、如何开始」。保留三主题液态玻璃材质、可重复滚动入场、静态 GitHub Pages 和独立架构页。

## 信息分工

- 产品首页：明确一句话定位；首屏四项功能与手册直达；功能区按「名称 → 用途 → 实际成果 → 使用入口」编排；首页概览、桌面代码仓作为辅助能力说明。场景示意明确不是实际数据，不暗示小记、个人任务与研究任务自动互通。
- 使用手册：增加「从这里开始」功能地图、首次使用路径和图标/手机导航说明；保留安装、阅境轩、时光机、任务中枢、书籍 Wiki 四模块详细章节。Wiki 增加可直达的配置、编译、问答、研究、Skill、备份小节与可照着操作的实例。
- LLM Wiki 架构页：保留深入架构和开发背景，不让首页承担技术合同说明。

## 当前实现核对

阅读记录：滚动停止约 1.5 秒采集 Markdown 位置，PDF 页码变化时记录；回书架、切文件、离开页面或页面隐藏会刷新待同步状态。浏览器缓存用于恢复，成功后保存到服务端 SQLite；同一服务的其他浏览器可读取已同步记录，并非账号/云端同步。

阅读目录只从书架更换；手机主 Dock 为首页、阅境轩、时光机、任务中枢、Wiki，上方子 Dock 承担 Wiki/任务视图与操作。普通图标通过悬停或可访问名称识别，手机操作抽屉保留行名称。

模型：供应商可配置多个；支持系统凭据库中保存页面填写的 API Key 或环境变量模式；Runtime 选择已保存供应商后再保存并验证。模型能力声明按供应商填写，不承诺所有模型都有 1M 上下文。

独立存储：不依赖 Obsidian；小记、任务、书架和 Wiki 在 SQLite；图片和二进制研究成果在受管附件目录；数据库快照不包含原图，完整备份另保留图片。原书只读。Wiki 只编译 Markdown 文件夹，PDF 仅阅读。
