# 手机端统一滚轮日期选择

## 范围与设计

- 统一替换任务/子任务开始与结束日期、时光机筛选日期、Wiki Token 用量范围的日期选择入口。任务日历仍是日程视图，不改成滚轮。
- `AppDatePicker` 在宽度不大于 768px 时使用共用底部抽屉，桌面继续透传 Element Plus 日期组件及现有配置。
- 年/月/日三列使用共用的可中断弹簧轨道接管拖动、惯性与归位，居中高亮、两端渐隐；44px 行高，短横屏缩减可见行数，不缩小触控目标。原生 scroll-snap 的硬吸附已替换：范围内 1:1 跟手，90ms 位置采样估算释放速度，指数减速投影后吸附整行；边缘使用渐进橡皮筋阻力，反向抓取从当前呈现位置继续。复用现有 springTrack（response .36 / damping .94），不另起一套弹簧实现。
- 选择只修改草稿；确认后一次性提交，取消、遮罩与返回手势不改变业务值。确认时读取当前滚轮位置，避免惯性未结束而提交旧日期。
- 范围共用三列滚轮，通过起止段切换编辑；改开始超过结束时结束跟随，改结束早于开始时开始跟随，界面始终显示有效范围。不改变任务表单原有起止校验。
- 公历闰年与大小月联动，31 日切换至短月时夹到月底。使用本地年月日序列化，不经 UTC ISO 字符串，保留调用方 Date / YYYY-MM-DD 的既有合同。
- 年份默认覆盖 1900 至当前年后 100 年，已有值超界时扩展，不静默裁掉历史或未来日期；清空仅在调用方允许时提供。
- 复用 MotionModal 的手势、嵌套焦点、滚动锁定与主题材质，避免抽屉打开时页面右移。窗口切回桌面时关闭滚轮，卸载后不残留事件或弹窗。

## 实施与验证

1. 先补纯日期/范围/滚轮索引边界测试与所有调用方的接入合同，确认旧实现不能满足需求。
2. 实现共用日期状态函数、惯性滚轮列与跨端组件，再替换全部页面入口。
3. 清理旧手机弹出日历定位补丁，保持电脑端样式不变。
4. 用全量拦截 API、禁用真实代理的浏览器验证任务、嵌套时光机筛选、用量范围；检查取消/清空/确认、月底闰年、连续滚动、短横屏、三主题、键盘和桌面回退。不得修改真实数据。
5. 运行全量前端测试、类型检查与生产构建，自审与简化。当前流程类 skills 不可用，按等价的计划、测试先行、验证流程执行；界面与手势遵守已读取的 apple-design。

## 验证记录

- 全量前端 479 项测试通过，类型检查与生产构建通过；保留现有较大分包提示。没有修改或重建运行中的服务。
- 纯日期、手势时钟和接入合同覆盖闰年/大小月、本地时区序列化、起止联动、速度交接、渐进边缘阻力、回弹中接管、反向拖动、停顿后不误惯性、确认中止动画、快速键盘与小幅触控板累积。外部日期变化和卸载会取消旧轨道，不触发过期目标。
- `verify-mobile-date-wheels.mjs` 全量模拟 API、关闭真实代理，验证 390×844、320×568、667×375 与浅色/深色/护眼共九种组合。任务编辑和子任务、时光机 Date 模型、Wiki 字符串范围均实际打开和操作；取消不改值、确认只发一次筛选、清空可选且必填日期不能清空。未写真实任务、小记、配置或数据库。
- 390px 浅色场景同时验证鼠标与 CDP Touch 的真实 Pointer 路径；短横屏缩为三行且保持 44px 触控目标。切换至桌面时滚轮和滚动锁释放；桌面仍显示既有日历。
- 年份轨道边界在每次打开时确定，手势中不随经过的年份缩短，避免历史/未来日期扩展轨道后惯性被反复重置。时光机独立起止日期交叉时同步按本地日期重排，避免向后端发送颠倒区间。
- 浏览器模拟不等同于 iOS/Android 真机；正式设备的系统触感和刷新率仍可能不同。本次无新增依赖、无后端/数据库迁移、无自动提交。
