# 清透玻璃与边缘折射

## 目标与边界

参考用户提供的小艺截图：中央透光，圆角边缘有柔和厚度；滚动文字穿过玻璃边缘时发生连续的轻微弯折与渐变模糊。前景文字、图标和点击区域不变形。取消上一版浮动控件全区域 10px 模糊和偏蓝灰色覆盖，不增加页面背景光斑。

使用 apple-design 的 clear material / scroll-edge separation 原则；正文、表单、弹窗仍优先可读性。保留 Dock 已接受的收缩、下沉和回弹路径，保留 PDF 窗口渲染与全屏切换减负。

## 实施

1. 先写圆角边缘位移场测试：中心中性、边缘渐变、圆角法向连续、大小有上限。
2. 共享材质降低浮动区域的底色与中央模糊；高光只在边缘，不在中心画白色光斑。
3. 增加独立的、无交互的背景光学层。Chrome/Chromium 使用有界的圆角位移贴图 + SVG backdrop filter；Safari/Firefox 默认使用清透中心与渐变模糊边缘，不以 CSS.supports(url) 作为真正支持的证明。
4. 只对手机 Dock、阅境轩底部工具栏、问答输入栏、官网导航启用圆角折射层；其他控件通过统一材质改善。顶部栏/电脑全屏标题使用开放式渐变滚动边缘（见补充），不使用封闭透镜。不复制正文 DOM、不捕获用户内容、不为每张卡片生成贴图。问答正文滚动到输入栏下方，预留 100px 末尾留白，最后一条来源仍完整可达。
5. 尺寸变化防抖后更新贴图；滚动不运行 JS，动画过程中复用贴图；不可见时释放位移资源。卸载移除观察器、偏好监听与 SVG 节点。地图最多 512×160 像素，不乘设备 DPR。
6. 减少透明度/高对比/强制色彩时关闭光学层并恢复实底；全屏过渡期间关闭工具栏光学层。材质变化不拥有导航动画或布局。
7. 用纯文字暗色夹具直接观察折射，再验证真实页面的三主题、窄屏、Dock 展开收缩、输入与弹层。跑前端/官网回归和构建，检查资源清理及点击透传。

## 依据

- [MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)：背景滤镜不作用于前景文字。
- [MDN feDisplacementMap](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/feDisplacementMap)：用颜色通道提供空间位移。
- [WebKit 245510](https://bugs.webkit.org/show_bug.cgi?id=245510)：截至本次核实，SVG backdrop reference filter 仍有兼容性问题，因此不在 WebKit 上强制开启。

这是网页端的有界光学增强，不声称跨浏览器复现原生渲染；iOS 真机效果和帧率需设备验证。

## 补充：顶部开放式渐变边缘

用户指出参考图顶部不是有轮廓的玻璃胶囊，而是渐变过渡。定位到手机全局标题、阅境轩工具栏仍继承浮动控件的内描边/阴影，全屏 h1 还有显式边框、圆角、封闭高光；统一改用 `data-glass="scroll-edge"`。

- 顶部容器没有描边、阴影、底色或自身背景滤镜。独立背景层向下延伸 36px，通过多级透明遮罩淡出；顶部较强模糊也用单向遮罩提早淡出，不再沿四边画环形高光。标题与按钮不使用遮罩或前景滤镜。
- 手机全局标题沿用原有滚动状态，只渐变背景层的透明度；阅境轩工具栏的背景层高于后方正文，避免扩展渐变被正文面板覆盖。原有点击、返回、全屏、Dock 的布局和动画不变。
- 顶部层使用纯 CSS 模式，直接创建/卸载背景层，不注册几何、可见性或偏好监听，不创建 SVG 或位移贴图。无障碍偏好由共享 CSS 恢复实底，全屏过渡仍关闭光学层。清理函数可重复调用，旧清理函数不会影响替换的新层。
- 新增回归先失败再通过，覆盖角色接入、无底线、背景延伸/渐变、前景不受遮罩、无障碍实底和纯 CSS 模式无额外资源。
- 浏览器检查 390px 暗色文字夹具：标题高度 82px，背景淡出到 118px，边框为 0、阴影为 none、标题 filter/mask 均为 none，无横向溢出；手机真实阅读夹具顶部两栏同样没有边框/阴影。全屏标题滚动预览可见渐变模糊，退出后移除角色与光学层。
- 深色、浅色、护眼夹具均检查了正文经过顶部的渐变过渡。前端 340 项测试、官网 38 项测试、前端类型检查、两端生产构建、`dist_new` 内嵌产物和 Rust release 构建通过；未替换/重启正在运行的程序。

## 补充：手机阅读底栏的材质厚度

用户反馈手机阅境轩底栏过于透明。原因是该栏直接复用小型浮动控件的低遮盖底色和 3px 中央模糊；密集正文穿过底栏时仍抢占视觉注意力。仅增加阅读底栏的专属材质权重，不改变顶部渐变、其他控件或 Dock。

- 底栏使用共享主题实底色的半透明混合：浅色 66%，深色/护眼 70%。图标和文档名使用主题主要文字颜色；极端黑/白背景上的颜色混合对比度测试不低于 4.5:1（前景标题处）。
- 原有有界圆角折射之后叠加 5px 柔化，CSS 兼容模式也同样生效；保留 10px 渐变边缘模糊、薄亮边和柔和斜向高光，不添加中心光斑，不修改前景字形、不复制正文。
- 不增加 JS、位移贴图或滚动监听；自动隐藏、打开目录时驻留、52px 四按钮、居中的文件名、减少透明度/强制色彩实底回退均保持不变。

- 390px 只读阅读夹具验证三主题的沉浸底栏、滚动显示和目录点击驻留。可见时 Chromium 使用 `url(#glass-lens-…) saturate(1.12) blur(5px)`；静止隐藏后回到 CSS 模式，无横向溢出。未更改正式书架数据，检查后恢复原预览主题。
