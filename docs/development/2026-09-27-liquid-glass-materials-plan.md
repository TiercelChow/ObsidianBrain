# 统一通透玻璃材质

## 目标与边界

参考用户提供的 macOS 控制中心截图，在保留浅色、深色、护眼配色及现有布局、Dock 物理动画的基础上，改善浮动功能层的透光、弧面边缘和层次。网站 website 不在应用前端范围内。浏览器的 CSS 材质是轻量光学近似，不等同于原生 Liquid Glass 的实时折射。

## 实施计划

1. 先增加材质契约测试，确认新材质模块缺失时测试失败。
2. 新增唯一材质入口 `styles/materials.css`，统一三主题透光填色、静态滤镜、边缘高光、内反光、环境阴影与不透明回退。旧类名通过集中适配消费同一套材质，不改变业务布局。
3. 区分浮动功能层（Dock、阅读栏、搜索栏、导航）、结构层（侧栏）、模态／字段菜单与正文内容层。内容卡片和内嵌表单不逐个模糊；模态更厚，以可读性为先。
4. 在有明确定位的浮动层上添加纯装饰的圆角高光环。支持遮罩时显示方向性亮边；不支持时仍有边框和内阴影。高光不占空间、不接受点击、不滤镜复制正文、不持续动画。
5. 阅读全屏标题接入共享材质，保留正文等宽和切换期间关闭昂贵滤镜的专项优化。背景改为静态环境色，降低噪点，避免“玻璃上的磨砂颗粒”。
6. 用隔离 Vite Mock 验证桌面／手机、三主题、弹层、贴字段菜单、减少透明度、高对比、不支持滤镜，以及 Dock 动画回归。禁止访问用户数据库、书架、真实模型服务。

## 验收

- 浮动层使用较轻的固定模糊与透明填色，背景颜色可辨认；表面没有局部大光斑。
- 圆球／胶囊保持同一材质及相同几何，装饰不覆盖按钮、不改变命中区域。
- 深色不成为纯黑薄膜，护眼不成为厚绿色塑料；正文表面不透出干扰阅读的密集背景文字。
- 输入控件及内容列表无多重 backdrop-filter；手机不增加持续 JavaScript／滤镜动画。
- 减少透明度、高对比及滤镜不支持时使用明确不透明表面；减少动态效果沿用现有行为。
- 单元测试、构建和隔离浏览器测试通过；视觉截图需人工查看。浏览器模拟不是 Safari／Android 真机帧率测量。

## 实施结果与验证

### Token 筛选栏对齐补充

隔离浏览器先复现桌面日期范围为 40px、调用方为 32px 的高度差。两者改为共用 `--usage-control-height`，桌面 40px、手机 44px，仍由响应式网格决定同排或分行，不改变筛选逻辑。三主题 × 六屏宽补充实际矩形高度和同排顶部对齐断言后通过；前端 260 项测试、类型检查和生产构建通过。提交前后端格式、Clippy 和测试通过（442 通过、3 项需真实环境的测试忽略）。

### 第三轮：主按钮、页内侧栏与配置控件

用户反馈实心蓝色主按钮、页内侧栏与 Skill 文件选择遗漏，Runtime 供应商和 Token select 溢出。新增失败契约与隔离浏览器用例后继续修复：

1. 系统主按钮及原生创建／发送／下载／确认按钮使用统一中性透明填色、方向性微反光和薄边缘；不改变动作逻辑和 Dock 运动。危险操作仍保留红色语义，键盘焦点与禁用状态明确，按钮不逐个执行滤镜采样。
2. 阅境轩文件树／目录、任务列表、时光机时间轴导航、Wiki 实体列表、问答上下文与配置导航使用结构层材质；模态内部侧栏只使用染色和边缘，避免重复滤镜。
3. Runtime 供应商从“说明 + 100% 下拉框”的超宽 flex 行改为受限单列，长名称省略并提供完整 title。Token 筛选取消 compact 固定宽度，以 minmax(0, ...) 和实际容器宽度自适应，窄面板分行。
4. Skill 导入及备份上传原生输入的 `visually-hidden` 类未定义，改用原生 `hidden` 属性，仅显示统一样式的「导入 ZIP／上传恢复」触发按钮；隔离测试检查文件选择事件且只取消，不上传文件。Skill 内容中的文件切换也复用玻璃动作控件，显示文件图标、选中态及 aria-pressed；多个按钮可换行，单个长路径省略且宽度不超过文件区域，保留完整路径 title，避免长文件名挤占正文空间。
5. 隔离用例覆盖三主题、320/390/667/900/1100/1440px，检查实际控件矩形而不只看 document.scrollWidth；全程 Mock API，不接触真实配置、凭据或书架。

第三轮验证：

- 13 项材质契约、全套 257 项前端测试、TypeScript 检查和生产构建通过。新增断言先发现主按钮遗漏、文件切换选中态优先级和隐藏类缺失，再验证修复。
- 三主题 × 六种屏宽的按钮／配置控件用例通过：主动作与文件选中态共享中性光学填色，危险操作保留可读的语义颜色，供应商与 Token 控件边界位于容器内；Skill 导入和备份上传都能触发文件选择器，测试仅取消，不上传或恢复文件。
- 四尺寸 × 三主题材质回归、四尺寸 Wiki 五页及全配置分区布局回归通过。人工检查桌面／手机、浅色／深色／护眼、长文件名弹窗及导入／备份操作截图。
- `make build` 通过，更新 `frontend/dist_new` 并重新生成 release 二进制；未安装、启动或重启应用，未修改用户数据。构建仍有既有依赖注释、混合导入和大包提示，不涉及此次样式缺陷。

### 第二轮：消除局部发白与遗漏的旧材质

用户反馈仍有毛玻璃残留，背景光影导致局部发白。检查发现 App 与阅读全屏各自保留大面积径向光晕；日历、时光机手机工具栏、图表预览和临时反馈组件还在独立定义滤镜。

1. 删除应用背景光晕、颗粒及全屏重复的环境光，让背景为主题基础色；玻璃质感来自表面边缘而非人为提亮背景。
2. 正文／内容表面不叠加白色 sheen；浮动层降低体积填色及表面反光，把高光限制在薄边缘。
3. 全部组件内的滤镜改为语义材质 token 或 `none`，补齐日历、次级工具栏、提示、预览按钮与统一遮罩。避免新全局样式只覆盖部分旧实现。
4. 图表预览画布保持不透明、无滤镜，图像查看器保留深色遮罩与白字控制层；这两类内容不应为了玻璃而降低识别度。
5. 增加源码覆盖契约和隔离浏览器检查，验证背景无光斑、新增消费者、嵌套滤镜与三主题可访问性回退；不改变 Dock 运动参数或用户数据。

第二轮验证：

- 9 项材质契约及全套 253 项前端测试通过；契约扫描 `src` 内所有 Vue／CSS 和 `index.html`，不允许组件继续独立设置 blur 配方。滤镜参数只在 `materials.css` 中定义。
- Vite／TypeScript 生产构建通过。应用背景、正文内容及全屏重复光晕检查通过；手机时光机的工具行保持透明，独立搜索／按钮玻璃，不增加整块矩形背景。
- 隔离材质矩阵覆盖四种尺寸 × 三主题，以及首页、阅境轩、时光机、任务中枢、代码仓、灵感熔炉、智识雷达、知识库与配置弹层；检查了真实模拟图表、图像和日历场景。每张截图检查当前可见 DOM 的滤镜归属，没有独立滤镜残留。
- Wiki 五页与全部配置分区的四尺寸布局回归通过；Dock 物理回归通过，主体收拢约 355–356ms，运动参数不变。
- 已人工查看普通／沉浸阅读、图表查看、图像查看、日历和时光机截图。真机帧率及原生折射仍不在此次验证结论内。
- 核实后端以 `rust-embed` 使用 `frontend/dist_new`；`make build` 已通过，更新对应目录并重新编译 release 二进制 `backend/target/release/obsidian-brain`。构建不执行应用，不安装或自动重启服务，不触碰用户数据库。运行旧 release 进程时仅刷新网页不能更新其内嵌资源，需切换到新二进制并重启。
