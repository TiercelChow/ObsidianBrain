## 1. 模块概述

### 1.1 定位

时光机模块为 ObsidianBrain 知识引擎提供 **个人时光记录与回顾** 能力。它允许用户随时记录"小记"（类似微信朋友圈），支持文本和图片，以时间线形式展示，帮助用户回顾思考历程、记录灵感碎片、追踪个人成长。

**核心理念**：从被动采集改为主动记录，让用户成为时间线的创造者而非旁观者。

### 1.2 核心价值

| 用户痛点 | 时光机模块的解决方式 |
|---|---|
| 碎片化想法无处记录 | 随时记录"小记"，支持文本和图片 |
| 回顾过往思考困难 | 时间线形式展示，按时间倒序排列 |
| 灵感转瞬即逝 | 快速记录，后续可关联到正式笔记 |
| 缺少个人成长轨迹 | 时间线可视化展示思想演变 |

### 1.3 设计原则

- **主动记录**：用户主动创建小记，而非被动采集
- **轻量快速**：小记应快速创建，不需要复杂的分类和标签
- **时间线可视化**：类似微信朋友圈的无限滚动时间线
- **Obsidian 原生存储**：使用 Obsidian 的 Timeline 文件夹存储，每月份一个 Markdown 文件
- **可追溯**：每条小记都有精确的时间戳，支持按时间筛选

## 2. 功能需求

### 2.1 小记管理 (Memo Management)

#### 2.1.1 创建小记 (Create Memo)

用户可以随时创建一条小记，支持以下功能：

**输入**：
- `content`: 小记内容（Markdown 格式，支持文本和图片）
- `images`: 图片列表（可选，存储到 Obsidian Timeline 文件夹）
- `tags`: 标签列表（可选，用于后续筛选）

**行为**：
1. 记录精确时间戳（精确到秒）
2. 将小记内容追加到当月的 Markdown 文件中（如 `Timeline/2026-06.md`）
3. 图片存储到 `Timeline/images/` 子文件夹
4. 返回创建成功的小记 ID

**文件格式**（`Timeline/2026-06.md`）：
```markdown
# 2026年6月 时光机

## 2026-06-02

### 14:30:25
这是一条小记，记录一个想法...

![[Timeline/images/2026-06-02-143025-1.png]]

---

### 15:45:12
又一条想法...

---
```

#### 2.1.2 浏览时间线 (Browse Timeline)

以时间线形式展示所有小记，类似微信朋友圈：

**UI 设计**：
- **布局**：左侧时间线（窄列），右侧内容区（宽列）
- **滚动联动**：左侧时间轴高亮跟随右侧视口顶部对应的日期（scroll-spy）；初次加载自动高亮最新一天，高亮日移出左轴视口时左轴自动跟随滚动
- **滚动方式**：无限滚动（向下滚动加载更多）
- **排序**：按时间倒序（最新在上）
- **分组**：按日期分组，每组显示日期标题

**展示内容**：
- 时间戳（精确到分钟）
- 小记内容（Markdown 渲染）
- 图片（如果有）
- 标签（如果有）

**分页**：
- 每次加载 20 条小记
- 滚动到底部自动加载下一批
- 支持按时间范围筛选

#### 2.1.3 时间筛选 (Time Filtering)

支持按时间范围筛选小记：

**预设范围**：
- 今天
- 最近 7 天
- 最近 30 天
- 本月
- 上月
- 自定义日期范围

**交互**：
- 提供日期选择器
- 支持快速切换预设范围
- 筛选结果实时更新

#### 2.1.4 内容搜索 (Content Search)

支持在小记内容中搜索关键词：

**功能**：
- 全文搜索（在小记内容中搜索）
- 标签搜索（按标签筛选）
- 支持组合搜索（时间范围 + 关键词）

**交互**：
- 搜索框支持实时搜索（防抖 300ms）
- 搜索结果高亮显示关键词
- 搜索结果按相关性排序

### 2.2 数据存储 (Data Storage)

#### 2.2.1 文件存储

**存储位置**：
- 小记文件：`Timeline/YYYY-MM.md`（每月份一个文件）
- 图片存储：`Timeline/images/YYYY-MM-DD-HHMMSS-N.png`
- 元数据：SQLite 数据库（用于快速查询）

**文件命名规范**：
- 月份文件：`YYYY-MM.md`（如 `2026-06.md`）
- 图片文件：`YYYY-MM-DD-HHMMSS-N.png`（N 为序号）

#### 2.2.2 Markdown 格式

**月份文件结构**：
```markdown
# YYYY年MM月 时光机

## YYYY-MM-DD

### HH:MM:SS
小记内容...

---

### HH:MM:SS
又一条小记...

---
```

**格式说明**：
- 一级标题：月份标题（如 `# 2026年6月 时光机`）
- 二级标题：日期标题（如 `## 2026-06-02`）
- 三级标题：时间戳（如 `### 14:30:25`）
- 分隔线：`---` 分隔不同小记
- 图片：使用 Obsidian 的 `![[]]` 嵌入语法

#### 2.2.3 SQLite 元数据

**表结构**：
```sql
CREATE TABLE memos (
    id          TEXT PRIMARY KEY,     -- UUID
    timestamp   DATETIME NOT NULL,    -- 精确时间戳
    date        TEXT NOT NULL,        -- YYYY-MM-DD
    content     TEXT NOT NULL,        -- 小记内容（纯文本，不含图片）
    tags        TEXT,                 -- JSON 数组
    image_count INTEGER DEFAULT 0,    -- 图片数量
    file_path   TEXT NOT NULL,        -- 月份文件路径
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_memos_timestamp ON memos(timestamp DESC);
CREATE INDEX idx_memos_date ON memos(date);
CREATE INDEX idx_memos_tags ON memos(tags);
```

### 2.3 工具接口 (Tool Interface)

#### 2.3.1 创建小记

**工具名称**：`create_memo`

**参数**：
```json
{
  "content": "这是一条小记",
  "images": ["path/to/image1.png", "path/to/image2.png"],
  "tags": ["灵感", "想法"]
}
```

**返回**：
```json
{
  "id": "memo-uuid",
  "timestamp": "2026-06-02T14:30:25Z",
  "file_path": "Timeline/2026-06.md"
}
```

#### 2.3.2 浏览时间线

**工具名称**：`browse_timeline`

**参数**：
```json
{
  "start_date": "2026-06-01",
  "end_date": "2026-06-30",
  "limit": 20,
  "offset": 0
}
```

**返回**：
```json
{
  "memos": [
    {
      "id": "memo-uuid",
      "timestamp": "2026-06-02T14:30:25Z",
      "content": "这是一条小记...",
      "images": ["Timeline/images/2026-06-02-143025-1.png"],
      "tags": ["灵感"]
    }
  ],
  "total": 42,
  "has_more": true
}
```

#### 2.3.3 搜索小记

**工具名称**：`search_memos`

**参数**：
```json
{
  "query": "关键词",
  "start_date": "2026-06-01",
  "end_date": "2026-06-30",
  "tags": ["灵感"],
  "limit": 20
}
```

**返回**：
```json
{
  "memos": [
    {
      "id": "memo-uuid",
      "timestamp": "2026-06-02T14:30:25Z",
      "content": "这是一条关于**关键词**的小记...",
      "images": [],
      "tags": ["灵感"],
      "score": 0.85
    }
  ],
  "total": 5
}
```

### 2.4 UI 设计

#### 2.4.1 页面布局

**整体布局**：
```
┌─────────────────────────────────────────────────────┐
│  [创建小记按钮]                    [搜索框] [筛选]  │
├──────────┬──────────────────────────────────────────┤
│ 时间线   │                                          │
│ (窄列)   │  内容区（宽列）                          │
│          │                                          │
│ 2026-06  │  ┌─────────────────────────────────────┐│
│  ├─ 02   │  │ 14:30:25                            ││
│  ├─ 01   │  │ 这是一条小记...                     ││
│          │  │ ![[image.png]]                      ││
│ 2026-05  │  │ #灵感 #想法                         ││
│  ├─ 28   │  └─────────────────────────────────────┘│
│  ├─ 27   │                                          │
│  ...     │  ┌─────────────────────────────────────┐│
│          │  │ 15:45:12                            ││
```

**设计要点**：
- **左侧时间线**：宽度 200px，显示年月日树形结构
- **右侧内容区**：宽度自适应，显示小记内容
- **无限滚动**：滚动到底部自动加载更多
- **响应式**：移动端时间线可折叠

#### 2.4.2 创建小记对话框

**对话框设计**：
- 标题：`创建小记`
- 内容区：多行文本框（支持 Markdown）
- 图片上传：支持拖拽上传、粘贴上传
- 标签输入：标签输入框（支持自动补全）
- 按钮：`取消`、`发布`

#### 2.4.3 时间筛选器

**筛选器设计**：
- 预设范围按钮：今天、7天、30天、本月、上月
- 自定义日期选择器：起止日期选择
- 实时筛选：选择后立即应用

#### 2.4.4 搜索框

**搜索框设计**：
- 位置：页面顶部右侧
- 防抖：300ms 防抖
- 实时搜索：输入后立即搜索
- 搜索范围：小记内容 + 标签

## 3. 非功能需求

### 3.1 性能需求

| 操作 | 目标延迟 | 说明 |
|---|---|---|
| 创建小记 | < 500ms | 写入文件 + SQLite |
| 浏览时间线 | < 200ms | 从 SQLite 查询 |
| 搜索小记 | < 300ms | SQLite 全文搜索 |
| 时间筛选 | < 100ms | SQLite 索引查询 |

### 3.2 存储需求

- **SQLite 数据库**：存储小记元数据（用于快速查询）
- **Markdown 文件**：存储小记内容（用户可读）
- **图片存储**：PNG 格式，压缩存储

### 3.3 兼容性

- **Obsidian 兼容**：生成的 Markdown 文件可在 Obsidian 中正常打开和编辑
- **图片兼容**：使用 Obsidian 的 `![[]]` 嵌入语法
- **搜索兼容**：SQLite 全文搜索支持中英文

## 4. 接口约定

### 4.1 与 Obsidian API 的接口

时光机模块直接使用 Obsidian Local REST API 进行文件操作：

| 操作 | Obsidian API | 说明 |
|---|---|---|
| 写入小记 | `PUT /vault/Timeline/YYYY-MM.md` | 追加到月份文件 |
| 上传图片 | `PUT /vault/Timeline/images/...` | 上传图片文件 |
| 读取小记 | `GET /vault/Timeline/YYYY-MM.md` | 读取月份文件 |
| 搜索小记 | SQLite 全文搜索 | 不依赖 Obsidian API |

### 4.2 与 LLM 的接口

时光机模块提供以下工具供 LLM 调用：

| 工具 | 说明 |
|---|---|
| `create_memo` | 创建小记 |
| `browse_timeline` | 浏览时间线 |
| `search_memos` | 搜索小记 |

### 4.3 错误处理

| 错误场景 | 处理方式 |
|---|---|
| Timeline 文件夹不存在 | 自动创建 |
| 月份文件不存在 | 自动创建 |
| 图片上传失败 | 返回错误，小记不创建 |
| SQLite 写入失败 | 返回错误，提示用户 |

## 7. 附录

### 7.1 Markdown 格式示例

**完整月份文件示例**（`Timeline/2026-06.md`）：
```markdown
# 2026年6月 时光机

## 2026-06-02

### 14:30:25
今天想到了一个有趣的项目想法：用 Rust 写一个知识管理系统...

![[Timeline/images/2026-06-02-143025-1.png]]

#知识管理 #Rust #项目想法

---

### 15:45:12
又想到了一个改进点：可以加入时间线功能，让用户记录碎片化想法。

---

## 2026-06-01

### 09:15:33
早上读了一篇关于 RAG 的论文，有些想法...

---
```

### 7.2 SQLite 查询示例

**按时间范围查询**：
```sql
SELECT * FROM memos
WHERE timestamp BETWEEN '2026-06-01' AND '2026-06-30'
ORDER BY timestamp DESC
LIMIT 20 OFFSET 0;
```

**全文搜索**：
```sql
SELECT * FROM memos
WHERE content MATCH '知识管理'
ORDER BY timestamp DESC
LIMIT 20;
```

**标签筛选**：
```sql
SELECT * FROM memos
WHERE tags LIKE '%灵感%'
ORDER BY timestamp DESC
LIMIT 20;
```
